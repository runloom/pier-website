Pier 0.1.63 (2026-11-20) has been released. This version includes the following updates.

## Fixes

- **Agent panels can now be moved to other windows normally.** Previously, moving one would show “Cannot move to this window” and leave the original tab behind; now, after the target window takes over, the tab in the original window closes properly.
- **Pi’s status no longer goes blank for no reason.** If Pi’s own settings have disabled Pier’s status extension, Settings → Agents → Pi will directly explain why and tell you how to re-enable it.

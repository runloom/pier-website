Pier 0.1.54 (2026-10-27) has been released. This release includes the following updates.

## Fixes

- **Mermaid diagrams in Markdown no longer falsely report that they cannot be rendered.** Mermaid outputs HTML-serialized fragments, but the previous parser read them as XML, so browser-inserted `<br>` tags were treated as formatting errors; they are now parsed as HTML, and valid diagrams render normally.
- **Git-ignored items in the file tree are dimmed again.** After enabling “Show ignored items,” the ignore index was previously no longer loaded, so ignored items were indistinguishable from regular files; now ignored items remain dimmed and display Git status markers.

Pier 0.1.40 (2026-09-06) is now available. Here’s what’s changed in this release.

## Added

- **Native scroll-to-bottom for the terminal.** `Cmd+↓` / `Cmd+End` can now reach the bottom in interfaces without shell prompt markers.
- **Files local diff quick preview.** From the source gutter and Markdown change color bar, you can directly open a preview of the current document’s local modifications.

## Changed

- **Terminal status bar git chip now consistently uses the all-caps GIT label.**
- **Multi-agent launch commands now include yolo direct-start parameters.** Covers Droid, OpenCode, Kilo, Mimo Code, and OMP.

## Fixed

- **File tree no longer causes scroll conflicts or jitter after switching changes.**
- **Grok accounts no longer show email overflow or stale membership status.**
- **Task onboarding now connects Linear/Jira instead of pasting opaque tokens.**
- **The review tree is no longer squeezed by the splitter handle when dragged to maximum width.**

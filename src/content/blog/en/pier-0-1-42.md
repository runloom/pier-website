Pier 0.1.42 (2026-09-11) is released. Here's what's new in this version.

## Added

- **Canvas interactive flowcharts.** Authors write only swimlanes, steps, and connections; after host validation, the main path, bypass, return, and failure lines are drawn. Swimlanes are boxes with a top bar and can stack phases, group boxes, and a legend derived from node types; at rest, the main path is thicker and the recovery band is visible; on hover, related connections flow in their direction.
- **Canvas interface flows.** Multi-screen paths are written as just a frame table; the host draws polylines, a start flag, a legend, and label positions.
- **After a file is deleted, open tabs remain.** The body continues to display with a notice above; saving rebuilds it at the original path. Differences caused only by deletion don't light up the unsaved dot, and closing the tab no longer asks whether to save.
- **File tree and review tree support highlighted multi-select.** Selection is a set; activation is a single item. Right-clicking a selected item acts on the whole set.

## Changed

- **Canvas skill templates and prompts deduplicated.** One starter per shell / recipe (the component directory uses the materials canvas directly, so no separate kit template is made); rules live only in SKILL, the corresponding reference, or pack.
- **Flowcharts in Markdown and the canvas match the paper color.** Groups, nodes, and connections default to the same color set as the document paper.

## Fixed

- **macOS no longer prompts for unused Screen Recording, Camera, Microphone, and Bluetooth.** Startup and everyday use no longer ask for these permissions; release builds no longer include Electron's default capture usage descriptions. If an older version was previously granted Screen Recording and still prompts after updating: fully quit Pier, toggle the switch off and back on in System Settings, then launch. The new version no longer needs Screen Recording.
- **Flowcharts are drawn in the correct order: polylines under cards, hover shows a glow, and the recovery band no longer tints connections.**
- **Release Enhanced Input drafts and attachments after closing a terminal.** Collapsing the input box or switching tabs still preserves unsent content; after terminal close is confirmed, clear the message body, edit snapshot, comments, and attachments, and immediately release pending attachment operations even if the previous file request hasn't returned. Late results don't affect a newly opened terminal; after the terminal is successfully moved to another window, the original window also releases this input data, without closing running terminals.
- **After reopening Enhanced Input, attachments and send results no longer interfere with new drafts.** Completed file selections and pastes are written to the current input box, and content completed while collapsed is restored when it is reopened; completion of an old message send won't clear content edited later or close a newly opened input box. During sending, duplicate submission is disabled, and the body can still be edited.
- **Expired Grok memberships no longer show as currently active.**
- **Grok terminals no longer lose their colors after restart.**
- **Large review trees and change diffs can scroll normally.**
- **When copying a tab to another window, the original source tab remains.**
- **Opening Markdown returns to the last reading position.**
- **The terminal view remains after the agent stops.** After the agent is stopped or the process exits, terminal content remains in the panel.

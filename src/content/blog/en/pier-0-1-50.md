Pier 0.1.50 (2026-10-22) has been released. This version includes the following updates.

## Added

- **When opening a parent directory that contains multiple repositories, each repository hides files according to its own rules.** As the file panel expands directories, it detects the `.git` inside them; sub-repositories' `node_modules`, build artifacts, and similar files are hidden according to that repository's own ignore rules, and change indicators are shown per repository. "Go to File" also uses that repository's ignore list when entering a sub-repository.

## Fixed

- **Large directories are no longer re-read in full on a periodic basis.** When system file watching cannot be set up, the file panel and open documents perform fallback refreshes with backoff, rather than re-reading the entire tree and all documents on every polling cycle; once watching is restored, they return to instant refresh.

Pier 0.1.36 (2026-09-02) is here. Here’s what changed in this release:

## New

- **Task tracking panel.** The official plugin puts GitHub, Linear, and Jira issues onto project panels and the canvas. Linear / Jira items are grouped by workflow and remember drag-and-drop order; GitHub items remain grouped by assignee.
- **Phone can reconnect to your computer outside the LAN.** After pairing, it wakes the Mac through the rendezvous cloud and push notifications—no need to be on the same network segment.
- **Drag tabs out of the window.** When you drag a tab outside Pier, the source tab collapses immediately and the target window pre-warms before appearing—no more bouncing back or waiting on a blank window.
- **Conflict review and normal diff share a single view.** Unchanged lines can be expanded; file-level conflicts still show the workspace content and resolve buttons.
- **Markdown preview shows change bars against HEAD on the left.** The thin gutter aligns with source code review and doesn’t block comments or the outline.
- **Markdown table column widths are draggable and remembered per table header.** Editing cells no longer loses column widths; changes are applied on release, and Escape cancels. Right-click in the preview jumps back to the source.
- **Canvas remembers where you left off.** After panning or zooming, it restores around the world-coordinate center; images, diagrams, Markdown, and Canvas share the same zoom controls.
- **Copy path is now a separate menu item.** File tabs, the tree, and search can copy the path or relative path and show the corresponding shortcut. Editor and review diff still copy paths with ranges.
- **Context menus prioritize the main action for each surface.** The review tree puts staging first; terminal search/clear no longer compete with copy/paste for the first group.
- **In the editor, ⌘D now continues to select the next occurrence.** This matches VS Code; split-screen shortcuts remain terminal-only.
- **Root README supports Chinese, English, Japanese, and Korean.** On GitHub, Simplified Chinese remains the default; switch to English, 日本語, or 한국어 at the top.
- **CLI user manual supports Chinese, English, Japanese, and Korean.** The GitHub entry `.pier/canvases/pier-cli-user-manual/README.md` remains Simplified Chinese by default; switch to English, 日本語, or 한국어 at the top. The in-app Canvas is still in Chinese.

## Changed

- **`/pier-canvas` infers the shell from the skill when none is specified.** The host only injects `locale=` and no longer tags `mode` / `recipe` / `content` by keywords. UI drafts go to the Canvas; decision drafts go to the reading flow. Explicit parameters still take precedence; typing just `/pier-canvas` still produces a decision draft.
- **Plugin rows and language services in Settings are more compact.** Plugin rows now show only the name and actions; language services became a vertical list, with installation as the next step.
- **Git groups in the command palette and Settings are now written as GIT.** Plugin name, settings title, command group, and command prefix are unified.

## Fixed

- **Canvas compilation failures now show an empty state.** If hot update keeps failing after a file edit, warnings no longer stay overlaid on the previous version of the Canvas. The warning when preview is still possible, save failures, paths outside the workspace, and partial review results are now a single toast pinned to the panel’s top edge.
- **Frame titles are readable on light surfaces.** Frame names and descriptions now switch ink color based on surface brightness instead of inheriting the host dark theme’s white text. Product UI inside frames still follows the app theme.
- **Live updates for files, git, and terminals are no longer dropped.** They keep up even during directory storms, and terminal status forwarding is no longer lost in the queue.
- **When a directory becomes a repository later, the status bar now fills in the git information.**
- **Running a task from review no longer steals the current panel.** It runs in the background with progress overlaid on the original panel.
- **Tooltip arrows no longer collapse into a dot.**
- **A command list with only one item no longer gets a group heading.** The command palette’s empty state puts common items under “Recent”.
- **Pasting an absolute path no longer appends it to the current directory.** This now matches VS Code / Zed.
- **Pressing Enter in a Chinese IME no longer writes the candidate as garbled text.**
- **Drag-selecting in the terminal no longer overwrites the system clipboard.** It goes to a private clipboard; copy, paste, and select all are no longer swallowed by the keyboard shortcut guard.
- **Copying across windows no longer pastes empty.**
- **System appearance changes now apply to windows immediately.**
- **After closing a panel group, focus stays on the most recently used group.** It no longer jumps to the earliest group in the top-left corner.
- **Kimi can now recover from a failed empty turn.** Authorization requests enter a waiting state.
- **Agent update timeouts no longer pop up the raw npm kill-process text.**
- **Project memory no longer misreports already-written TOML MCP entries as partially connected.**
- **The phone back button now returns to the source session.** Multi-window no longer binds the wrong terminal; the workbench terminal title matches the desktop tab’s short name.
- **When a device is revoked, the phone is notified directly instead of showing a generic disconnect.** LAN and rendezvous-cloud entries for the same machine now merge into one row.

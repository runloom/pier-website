Pier 0.1.32 (2026-08-26) focuses on reworking the enhanced input. Attachments are now handled recognition-first, and input interactions align with mainstream chat input conventions.

## Recognition-first attachment track

- All attachments use a uniform **48×48** grid: images scale with `contain`; text and pasted content expose their opening thumbnail; other files show only a type icon with the name in a hover tooltip.
- The `#n` numbering is gone from the track to reduce visual noise.
- Too many attachments scroll horizontally instead of wrapping.

## Unified capsule chips

`@` paths, commands, skills, attachments, and review chips in the enhanced input now share one fully-rounded capsule style, consistent with the rest of the UI.

## Drafts and composition are preserved

- **Programmatic focus moves the caret to the end**: reopening or switching back to the enhanced input places the caret at the end of the draft instead of the start, matching mainstream chat inputs; clicking inside the body still positions by click.
- **Close/reopen keeps composition**: toggling the input off and on restores command / skill / `@` / attachment / review chips along with the top attachment track instead of degrading to plain text; sending still clears as usual.

## Layered Esc behavior

With a command / skill / `@` / `#` list open, Esc now collapses only the list instead of closing the whole input card; a second Esc after that closes the input.

Pier 0.1.48 (2026-10-20) has been released. This version includes the following updates.

## Added

- **CSV / TSV table preview and editing.** `.csv` / `.tsv` / `.tab` files now open as tables by default, with the ability to switch between table and source views. Supports cell editing, right-clicking row numbers/column headers to add or delete rows/columns, undo/redo, and toggling the first-row header and delimiter. Edits replace only the original text ranges of the cells touched; untouched quotes, line breaks, and other bytes remain unchanged. Large files automatically fall back to a read-only preview.

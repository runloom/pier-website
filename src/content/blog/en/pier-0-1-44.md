Pier 0.1.44 (2026-09-22) has been released. This version includes the following updates.

## Added

- **Conflict review shows only the current file at a time.** In Merge Changes, select an item; marked conflicts can be accepted and staged here. If the workspace file is missing and both sides can be read as text, the body is a diff of the current side against the incoming side. If the file is too large, has the wrong encoding, or cannot be read, and the file still exists, the primary button is Open File.

## Changed

- **Review shows changed blocks first.** The full text is read only when you expand collapsed unchanged lines. When the sidebar has already changed, the body waits for the list to refresh and no longer retries with a stale index.

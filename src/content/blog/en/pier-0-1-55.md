Pier 0.1.55 (2026-10-27) has been released. This version includes the following updates.

## Fixes

- **Opening a repository no longer leaves a `.pier/` directory in your project.** Previously, Pier wrote the worktree's local identifier record in the root directory of the opened repository, so even non-Pier projects ended up with an extra untracked directory. This record is now stored in Pier's own user data, kept separately per main repository, so project directories stay clean.

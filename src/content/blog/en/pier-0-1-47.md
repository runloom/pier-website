Pier 0.1.47 (2026-10-19) has been released. This version includes the following updates.

## Added

- **View `.mermaid` / `.mmd` files as diagrams directly.** When these files are opened from the file panel, the rendered diagram is displayed by default, and you can switch back to the source at any time; rendering, paper color scheme, and fullscreen viewing reuse the Mermaid code fences in Markdown, and invalid syntax shows a retryable failure message.

## Fixed

- **⌘C / ⌘V / ⌘A work again in the terminal.** The app menu's Copy/Paste/Select All roles dispatch these shortcuts to the current first responder, but the native terminal's first responder is handed over asynchronously based on renderer state. Before the handoff completes, the menu consumes ⌘C first and copies an empty web selection, so the terminal selection is never copied. Now, when the terminal owns the keyboard, the event router executes the corresponding clipboard action based on keyboard ownership first, no longer relying on first responder timing; web-side shortcuts and menu behavior remain unchanged.

Pier 0.1.45 (2026-09-23) has been released. Here's what's new in this version.

## Added

- **Run tasks now include setup commands.** When a mise configuration is present, you can trust and install the toolchain; when package.json, Composer, uv, or Poetry is present, you can install dependencies. If the corresponding program isn't available locally, these commands won't appear.

## Changed

- **Run tasks no longer list Zed tasks.** Terminals that are already open remain, but they no longer carry this task record.

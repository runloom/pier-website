Pier 0.1.51 (2026-10-23) released. This release includes the following updates.

## Fixes

- **With multiple Changes panels, right-clicking to expand/collapse directories only affects the one you clicked.** When multiple “Changes” panels are split out in the same window, the context menu could previously land on the most recently opened panel; it now targets the tree that opened the menu, based on the panel and review scope. If the tree is temporarily unavailable, a prompt is shown instead of silently doing nothing.

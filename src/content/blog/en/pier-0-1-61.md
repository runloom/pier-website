Pier 0.1.61 (2026-11-16) has been released. The updates in this version are as follows.

## Fixes

- **Switching back to the Markdown tab no longer re-parses the entire document.** When the preview is hidden and then shown again, the already-parsed document is reused, making back-and-forth switching in long documents more responsive and avoiding repeated memory usage.
- **Memory no longer keeps climbing when viewing many Mermaid diagrams.** The rendered diagram cache now has a total size limit; once exceeded, the oldest entries are evicted, keeping memory stable during long browsing sessions.

Pier 0.1.35 (2026-08-31) is now available. Here's what changed:

## New

- **Open project folder from review.** Right-click in the change tree, diff, or review tab to open a Files project-folder tab (directory tree only), rooted at the review's git root. It doesn't take over the review's main click, and no chip is added to the top bar.

- **Commit picker supports contiguous ranges.** In the Changes top bar's Commit picker, check one commit to review it immediately; check another to review the contiguous net diff from the previously selected commit. Only the checkbox column on the left is clickable.

- **macOS permission explanations and recovery path.** When accessing Desktop, Documents, or Downloads, the system explains why. After a denial, the file tree and the recovery tab point to Privacy & Security › Files and Folders instead of an error code.

## Changed

- **The product front door now sets the scene.** The root README and website show which terminals are waiting for you, and that files, editing, and Git live in the same window. The Canvas page is usable; the kanban and run-graph pages are still in progress. No more claims of replacing VS Code. The plugin section covers the current scope and doesn't frame third-party marketplaces as something we'll never do.

- **Canvas templates are now demo-grade.** The reading-flow, drawing-board, and kanban templates open ready to compare the two canvas modes side by side, instead of being empty shells.

- **Project memory covers more MCP clients.** All clients on the official MCP discovery surface register project memory (including Grok).

- **Agent count in the title bar can be hovered for details.** Like the notification bell, hovering shows list names and keyboard shortcuts.

- **Markdown diagram preview follows the reading surface.** Diagrams now sit on the reading page, and the wide-screen text measure is the default.

- **File tree and Git review share a tree width.** Both sidebars remember their width and are dragged together.

## Fixes

- **Confirming a commit shows progress.** After clicking commit, the button enters a waiting state to avoid double-clicking.

- **Review top bar commit is text-only.** The icon was removed from the button.

- **Moving a panel to another window now focuses the target window.**

- **Hovering on either side of a panel tab no longer reveals tick marks.**

- **Agent turn endings are no longer thrown off by stale logs.** Turn accounting uses native turn identity, and a new turn is opened only when a new tool starts. Hook events leaked by the graphical launcher are now discarded.

- **Agent names now display correctly.** Crush and Kilo Code no longer use the wrong labels.

- **pi / kimi can pick up where they left off using their native sessions.**

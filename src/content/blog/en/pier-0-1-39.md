Pier 0.1.39 (2026-09-04) has been released. This version includes the following updates:

## Added

- **Clicking a file in the terminal now opens it in Pier.** Source code and text go to the Files panel; web pages and email links are still handled by the system.
- **Window titles are now tied to the workspace identity.** When projects share the same name, the title includes the branch, parent directory, or pinned tab name; the “Move to Other Window” command uses the same set of names.

## Changed

- **The right-click menu no longer has extra separators.** Split, focus, and session actions are now grouped together.
- **The New menu folds the remaining entries under “Workspace”.** Run and Agents remain in their own groups.

## Fixed

- **The preview font-size control is no longer translucent and blurry.** It no longer leaves ghosting when overlaid on the terminal.
- **The transparent overlay no longer blocks clicks after dragging panels.**
- **Arrow keys no longer cause the terminal viewport to jump all the way to the bottom.**
- **After renewing Codex, the old expiration date is no longer treated as expired.** If the API hasn’t returned the member seat yet, deactivated members won’t be reactivated either.

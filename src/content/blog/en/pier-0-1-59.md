Pier 0.1.59 (2026-11-12) has been released. This version includes the following updates.

## Fixes

- **When opening Settings or a confirmation dialog, the terminal no longer disappears entirely or leaves residual edge artifacts.** The overlay only captures input; the terminal is dimmed with the same color instead of being punched out. The four corners outside the rounded card are filled back with the background color, and the card's outer shadow is now drawn separately beneath the compositing layer, so the terminal edges no longer show clipped black or bright borders. Fade-in/fade-out only changes opacity; the dialog remains static throughout, preventing the snapshot pipeline from falling behind.
- **When the workbench tab strip scrolls horizontally to the window edge, it no longer bounces back, and the overflow counter no longer jitters.** The tab strip is not a content scrolling surface; it stops when it reaches the horizontal edge. The overflow counter (▾ N) now uses tabular numerals, so its width remains stable when the number of digits changes.

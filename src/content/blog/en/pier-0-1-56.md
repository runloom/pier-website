Pier 0.1.56 (2026-10-28) has been released. This release includes the following updates.

## Fixes

- **Terminals created in the background no longer get stuck on a blank placeholder shell.** Terminal panels opened in the background by agent delegation previously waited for a visible frame before starting. Hidden panels would never get one, so switching to them showed only a placeholder. Now they start as soon as they are created in the background, so opening one gives you a usable terminal. Visible split panes, restored tabs, and cross-window transfers still wait for a real frame, and no longer flash unrendered content.

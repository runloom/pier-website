Pier 0.1.33 (2026-08-28) brings project setup and phone viewing into the product, and tightens reading, canvas, and Git review.

## Project setup is remembered

In Settings → Projects you can save CLI configuration for a repository (for example MCP). The next time you open that project, it is ready — no need to set it up again.

## A phone on the same network can look in

Pair a phone in Settings and, on the same LAN, view sessions, files, and changes.

## HTML / SVG preview

The files panel can preview HTML and SVG, with the same zoom gestures as image preview.

## A steadier Markdown column

The body uses a fixed comfortable width, and no longer stretches with the document font or preview zoom. Long paths wrap inside the column; text stays left-aligned.

## The canvas takes over the old Workbench panel

The canvas now builds its UI from plugin data and actions. The New Workbench command and the old Workbench panel are gone. Adding, removing, and signing in to accounts still happens in Settings. Pier is still a local dev workbench — that has not changed.

## A smaller installer

Every icon size is generated from one vector master. System fonts are preferred, so the extra bundled Chinese font is gone and the installer is about 31MB smaller.

## A steadier terminal and Git review

Long-running terminals no longer keep flickering. With focus in the terminal, Find and similar shortcuts go to the terminal first. Searching, jumping, and comments in Git review are easier to follow. After restarting Pier, unfinished sessions still show up and can be resumed.

Update, then open a project. Full changelog: [CHANGELOG](https://github.com/runloom/pier/blob/main/CHANGELOG.md).

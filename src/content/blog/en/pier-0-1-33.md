Pier 0.1.33 (2026-08-28) brings project configuration and phone viewing into the product, and tightens reading, canvas, and review.

## Project memory

In Settings → Projects you can register managed agent configuration for a repository (for example MCP). The next time you open that project, it is ready — no need to set it up again.

## Phone on the same network

Pair a phone in Settings and, on the same LAN, view sessions, files, and changes.

## HTML / SVG preview

The files panel can preview HTML and SVG, with the same zoom gestures as image preview.

## A comfortable Markdown column

The reading measure is a fixed comfortable width in root rem, and no longer stretches with the document font or preview zoom. Long paths wrap inside the column; text stays left-aligned, not justified.

## Canvas and Workbench

Canvas now composes from plugin data, actions, and the settings entry. The New Workbench command and the old Workbench panel are gone. Adding, removing, and signing in to accounts still happens in Settings.

## App icon and installer size

Every icon size is downsampled from one vector master. System fonts are preferred, so the extra bundled Chinese font is gone and the installer is about 31MB smaller.

## A steadier terminal and review

Long sessions no longer keep flickering; with focus in the terminal, Find and similar shortcuts go to the terminal first. git review search, placeholders, click-to-jump, and comment navigation are easier to follow. After restarting Pier, unfinished agent sessions still show up and can be resumed.

Update, then open a project. Full changelog: [CHANGELOG](https://github.com/runloom/pier/blob/main/CHANGELOG.md).

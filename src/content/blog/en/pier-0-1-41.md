Pier 0.1.41 (2026-09-06) released. This version contains the following updates.

## Fixed

- **Enhanced input: sending long Chinese text no longer shows `���` in agents.** Terminal writes are now chunked at character boundaries, so no Chinese character is split across two writes (which affected agents like Cursor that decode incrementally).
- **The file tree now remembers its expanded state after restart.** Persisted expanded directories are restored before first paint, so it no longer flashes fully collapsed.
- **The file panel empty state is now truly centered.** The hidden file tree no longer leaves an invisible placeholder that squeezes the layout.

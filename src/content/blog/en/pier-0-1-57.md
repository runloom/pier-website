Pier 0.1.57 (2026-11-09) has been released. This version includes the following updates.

## Fixes

- **Previewing web pages in Files no longer covers the terminal.** HTML pages with glass or blur effects would stack their layer above the terminal view, causing overlapping content and ghosting; now the terminal view always stays on top, and web pages appear only over real controls such as pane dividers, floating tab groups, and completion lists, so the terminal itself is never covered.
- **The terminal status bar no longer shows text from the previous frame.** When resizing the window or partially redrawing, the chips in the bottom status row would briefly appear twice, with the old copy left over from the previous frame; now the background is filled first before redrawing, and the status row keeps only the current content.

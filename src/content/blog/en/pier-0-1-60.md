Pier 0.1.60 (2026-11-15) has been released. This release includes the following updates.

## Added

- **View PDFs, Word documents, and Excel spreadsheets directly in Files.** Double-click a `.pdf` / `.docx` / `.xlsx` file to open it read-only in the panel: PDFs support page navigation, zoom, and fit-to-width, and in-page links remain clickable; Word documents are laid out in their original format (complex layouts may differ from the source file); Excel preserves multiple worksheets, number formats, and the document's own column widths. Column widths can be dragged and are remembered per worksheet, and cells can be copied directly. For PPTX, legacy `.doc` / `.xls`, and encrypted documents, the app explains why it can't preview them and provides an "Open in Default App" option; documents over 64 MB also get a clear message.

## Fixed

- **If a file is overwritten while previewing, you'll be prompted to view the current version.** A file changing during loading and a document exceeding the size limit now produce two different prompts: the former offers "Reload" and no longer treats the stale page as the latest content.
- **Deleted document tabs remained and kept showing the last preview.** After a file is deleted from disk, the page no longer goes blank or shows a read failure; a deleted notice remains at the top, and the file can be previewed again once restored.
- **Search bars, menus, and completion lists overlaying the terminal now have correct rounded corners and shadows again.** Overlay appearance is now sampled from the actual rendered card: corner radius, shadow, and fade-in/fade-out match the screen; pills no longer show square corners, and menus no longer appear "with corners but no shadow."
- **Scrolling the mouse wheel over the tab bar no longer pulls the tab row into an elastic bounce.** The tab bar is not a content scrolling surface, so scrolling stops at the end; the overflow count (▾ N) and similar indicators update once the gesture stops, instead of jumping back and forth during scrolling.

Pier 0.1.53 (2026-10-26) has been released. The updates in this version are as follows.

## Fixes

- **SVG images no longer disappear under sliding / onion-skin comparison.** SVGs have no pixel header, so their dimensions were previously treated as unknown and fell back to 1×1, shrinking the entire image to a single point; intrinsic dimensions are now read from the root tag’s `width` / `height` / `viewBox`, with support for `viewBox`-only markup, units (pt / mm / in, etc.), and scientific notation.

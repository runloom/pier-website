Pier 0.1.58 (2026-11-09) has been released. This version includes the following changes.

## Fixes

- **Split panes opened in the background by the agent no longer remain empty `Last login` shells.** Previously, when window identities did not match, split-pane sessions were treated as gone and their mappings were rebuilt, causing the newly opened teammate panel to lose its association and the process not to start; now the mapping is retained when liveness cannot be determined, background split panes start immediately, and failed placeholders are reclaimed.
- **Agent sessions are no longer lost when located across windows.** The host command previously mixed Electron window IDs with internal window IDs, which could position the panel in the wrong window; all IDs are now normalized to internal window IDs.
- **The terminal no longer disappears when Settings or confirmation dialogs are opened.** The dialog overlay was previously treated as a drawable region and used to backfill the terminal hole, erasing the entire terminal under opaque backgrounds; now the overlay only handles input capture, and the dialog card is rendered separately above the terminal.

Pier 0.1.43 (2026-09-16) released. The updates in this version are as follows.

## Added

- **fx agent support.** New agent `fx` (https://fx.sh): directory probing, launch, one-shot (`fx ask`), MCP/skill discovery, install and update sources. When the Grok plugin switches accounts, subscription credentials can be synced to `~/.fx/grok-auth.json` (login-type OIDC accounts only).
- **fx Herdr status channel.** The host impersonates a Herdr multiplexor, and fx reports idle/working/blocked over a Unix socket; sockets are isolated per instance userData, same-name panels across multiple windows fail closed, only fx panels get the ownership env injected, and ingest requires OSC to have lit fx.

## Fixed

- **Generalized peer-sync targets.** Codex/Claude keep a local narrow target set, while Grok exclusively uses fx targets; shared `PeerAvailability.fx` is optional, and old snapshots remain compatible.
- **Refreshed expired Grok remaining-resets live fixture.** A token expiring on 2026-09-12 caused 4 test cases to fail; rebuilt a same-shaped fixture expiring in 2030.
- **Corrected duplicate-discovery semantics for fx skills.** fx reads both `.agents` + `.claude`, with no deterministic resolution, so duplicate-discovery is reported as multi-root-scan.

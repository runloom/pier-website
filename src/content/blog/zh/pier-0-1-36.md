Pier 0.1.36（2026-09-02）发布。本版更新内容如下。

## 新增

- **任务跟踪面板。** 官方插件把 GitHub、Linear、Jira 的事项放到项目面板和画布上。Linear / Jira 按工作流分列并可记住拖放顺序；GitHub 仍按指派归列。
- **手机可在非局域网连回电脑。** 配对后经会合云和推送唤醒 Mac，不必跟电脑同一网段。
- **把标签拖出窗口。** 拖到 Pier 外面时来源标签立刻收起，目标窗预热后出现，不再弹回或先空白等一会儿。
- **审查冲突与普通对比同一套视图。** 未修改行可展开；文件级冲突仍显示工作区正文和决议按钮。
- **Markdown 预览左侧显示相对 HEAD 的变更条。** 细槽对齐源码审查，不挡住评论和大纲。
- **Markdown 表格列宽可拖、按表头记住。** 改单元格不丢列宽；松手才保存，Escape 取消。预览右键可跳回源码。
- **画板记住你看的位置。** 平移或缩放后按世界坐标中心回忆；图片、图表、Markdown 和画板共用同一套缩放控件。
- **复制路径拆成独立菜单项。** 文件标签、树和搜索可复制路径或相对路径，并显示对应快捷键；编辑器和审查对比仍复制带范围的路径。
- **右键菜单按表面排主工作。** 审查树暂存优先；终端查找和清屏不跟复制粘贴抢第一组。
- **编辑器 ⌘D 继续选下一处。** 与 VS Code 一致；分屏快捷键只给终端。
- **根 README 支持中英日韩。** GitHub 默认仍是简体中文；顶部可切换 English、日本語、한국어。
- **CLI 使用手册支持中英日韩。** GitHub 入口 `.pier/canvases/pier-cli-user-manual/README.md` 默认仍是简体中文；顶部可切换 English、日本語、한국어。应用内 Canvas 仍为中文。

## 变更

- **`/pier-canvas` 未指定壳时由智能体按 skill 推断。** 宿主只注入 `locale=`，不按关键词打 `mode` / `recipe` / `content`。界面稿走画板，决策稿走阅读流；显式参数仍优先；光敲 `/pier-canvas` 仍是决策稿。
- **设置里插件行和语言服务更短。** 插件行只留名称和操作；语言服务改成竖向清单，下一步是安装。
- **命令面板和设置里的 git 分组写成 GIT。** 插件名、设置标题、命令分组和命令前缀统一。

## 修复

- **画板编译失败改成空态。** 改文件后热更新仍失败时不再把警告盖在上一版画板上；还能预览时的警告、保存失败、工作区外路径、审查部分结果改成贴着面板顶边的一条提示。
- **浅色台面上的画框标题可读。** 画框的名称和说明按台面亮度换墨色，不再套宿主深色主题的白字。帧里的产品界面仍跟应用主题。
- **文件、git 和终端的实时更新不再丢。** 目录风暴时仍能跟上；终端状态转发不再被队列丢掉。
- **目录后来才变成仓库时，状态栏会补上 git 信息。**
- **在审查里运行任务不再抢走当前面板。** 后台跑、进度叠在原面板上。
- **提示气泡的小三角不再缩成一个点。**
- **命令列表只有一项时不再套分组标题。** 命令面板空态把常用项收到「最近」。
- **粘贴绝对路径不再被拼进当前目录。** 行为对齐 VS Code / Zed。
- **中文输入法回车不再把候选写成乱码。**
- **终端划选不再覆盖系统剪贴板。** 划选进私有剪贴板；复制、粘贴、全选不再被键盘门禁吞掉。
- **跨窗口复制后粘贴不再是空的。**
- **系统外观变化会立刻应用到窗口。**
- **关掉一组面板后焦点留在最近用过的那一组。** 不再跳到左上角最早那组。
- **Kimi 在空回合失败后能恢复状态。** 授权请求会进入等待。
- **智能体更新超时不再弹出 npm 杀进程原文。**
- **项目记忆不再把已写好的 TOML MCP 项误报成部分连接。**
- **手机返回键回到来源会话。** 多窗口不再绑错终端；工作台终端标题跟桌面标签短名一致。
- **设备被撤销时手机会直接提示，不再显示成泛化断线。** 同一台机器的局域网和会合云条目会合一行。

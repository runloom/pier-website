Pier 0.1.37（2026-09-03）发布。本版更新内容如下。

## 新增

- **Markdown 和审查里能预览 SVG。** 规范的 SVG 当作图片打开，不再落到二进制提示。
- **图表预览用同一套官方引擎。** Markdown、全屏和画板共用主题与源码整理；放大缩小时用点阵减轻负担。

## 变更

- **设置里的 MCP 页改成跨智能体清单。** 按 Pier 托管 / 项目内 / 用户配置分组，标明谁能用、谁还没有，以及本地进程或远程。智能体带名称，避免把 Grok 的 X 图标读成失败。`pier-memory` 在仓库项目里打开项目记忆。Pier 仍不改这些文件、不启动这些服务器。
- **打开家目录里的 MCP 配置不再出现空白页。** 工作区外的文件会显示真实路径和正文，不会伪装成当前项目里的 `config.yaml`。
- **新建菜单保持稳定目录。** 页脚「管理智能体…」贴着弹层；命令和技能搜索按同一套排序。
- **文件面板图片预览不再预留全屏标题带。**
- **手机 Web 壳改成远程驾驶舱样式。** 会话、审查和主机入口按驾驶舱信息架构重排。

## 修复

- **长时间开着应用后内存不再持续上涨。** 画布和积木热更新会拆掉上一版运行环境；用量请求不再为每次挑战开隐藏窗。
- **多个可见终端不再被反复重插。**
- **终端滚动条裁切对齐系统公式。**
- **把标签撕到新窗口时不再把预热窗当成已有目标。**
- **画布源码里的 `pier/canvas` 模块能被语言服务解析。**

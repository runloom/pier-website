Pier 0.1.54（2026-10-27）发布。本版更新内容如下。

## 修复

- **Markdown 里的 Mermaid 图表不再误报无法渲染。** Mermaid 输出的是 HTML 序列化片段，此前的解析器按 XML 读取，浏览器补全的 `<br>` 会被当成格式错误；现在按 HTML 解析，合法图表正常显示。
- **文件树里的 Git 忽略项重新淡化。** 打开「显示忽略项」后此前不再加载忽略索引，忽略项与普通文件看不出区别；现在忽略项保持淡化并显示 Git 状态标记。

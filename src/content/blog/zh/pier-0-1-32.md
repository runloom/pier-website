Pier 0.1.32（2026-08-26）聚焦增强输入的重做。这一版把附件处理从"占位图"改成"识别优先"，并把输入区的交互细节对齐主流聊天输入框的惯例。

## 附件轨改为识别优先

- 全部附件统一 **48×48** 等格展示：图片 contain 缩放；文本与粘贴内容露出开头缩略；其它文件只显示类型图标，名字放在悬停提示里。
- 附件轨上不再显示 `#n` 编号，减少视觉噪音。
- 附件过多时横向滑动，不折行、不挤压。

## 输入芯片统一胶囊形

增强输入里的 `@` 路径、命令、技能、附件与 review 芯片统一为全圆角胶囊样式，与整体界面语言一致。

## 草稿与编排状态完整保留

- **程序化聚焦光标置尾**：重新打开或切回增强输入时，光标落在草稿末尾而不是开头，对齐主流聊天输入框惯例；点击正文内仍按点击位置定位。
- **关开保留编排**：切换关闭再打开时，命令 / 技能 / `@` / 附件 / review 芯片连同顶部附件轨原样恢复，不再退化成裸文本；发送成功后照常清空。

## Esc 分层退出

命令 / 技能 / `@` / `#` 列表打开时按 Esc 只收起列表，不再连带关闭整张输入卡片；列表收起后再按一次 Esc 才关闭输入区。

升级后打开任意会话即可体验。完整变更记录见 [CHANGELOG](https://github.com/runloom/pier/blob/main/CHANGELOG.md)。

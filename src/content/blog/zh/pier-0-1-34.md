Pier 0.1.34（2026-08-30）发布。本版更新内容如下。

## 新增

- **设置里可开启接收候选版本。** 设置 → 更新新增「接收候选版本」开关（默认关闭）：开启后可在正式发布前收到候选版本，正式版发布后自动替换；普通用户不受影响。
- **把面板移到其他窗口。** 标签右键：两个窗口时直接移到另一窗口，多个窗口时从子菜单选目标。
- **命令行打开目录与文件。** `pier .` 与路径简写会聚焦已有工作区，或在编辑器打开文件（支持 `:行[:列]`）。
- **从审查页确认提交。** 命令与未提交审查共用同一入口，用确认卡提交当前更改；勾选不记住上次，也不回写「提交后推送」。
- **工程任务与文件图标更全。** 识别 Dart / CMake / Python / Go / Maven / Gradle 等工程文件并提供内置任务；Dart 优先工作区 FVM SDK。

## 变更

- **宿主发布增加候选版路径。** 常规发版先打 `vX.Y.Z-rc.N`（GitHub prerelease，不占 Latest、不发博客）；观察期后晋升正式 `vX.Y.Z`。显式触发「直接发布」可跳过候选。详见 `docs/release.md` 与候选版金标准规格。
- **相关面板插在当前标签后面。** 新开的相关面板落在当前标签右侧；标签缝、边距与悬停底与列表一致。
- **智能体 CLI 版本检测走权威远端。** Homebrew 核心配方读 formulae.brew.sh，不再把过期本机索引当最新；已知安装源不跨生态取最新或做更新计划。
- **只管理 Kimi Code。** 不再把 PATH 上的旧 Python `kimi-cli` 当成同一产品去更新。
- **项目记忆不必改仓库文件。** 已开启项目记忆的仓库，启动时由宿主把说明交给智能体。
- **窗口列表标题不再重复叶子名。** 主标题用工作区叶子目录；右侧只放不同的 git 分支或活动文件。

## 修复

- **分栏拖拽不再藏终端。** 拖分栏或浮层缩放条时，终端保持可见并跟锚点改尺寸；只有拖窗口边才走隐身占位。
- **对话框遮罩盖住标题栏。** 弹窗打开时自定义标题栏一并变暗；可点遮罩关闭的弹窗也能点标题栏关闭。
- **刷新后不再误关仍在跑的终端。** 接回会话时钉死标识；布局未就绪时不会按空列表关掉活终端。
- **全屏预览不再闪一下，复制图片可用。** 灯箱复用已有预览图；复制从已绘制的图片生成 PNG。
- **交给智能体的评论更干净。** 只发送定位位置和评论正文，不再附带界面标签和摘录。
- **增强输入菜单按开闭写打开或关闭。** 右键和命令面板不再写「切换」。
- **多文件审查折叠列表分隔线可见。** 分隔线改画在文件卡片上，不再被文件头盖住。
- **OpenCode 项目记忆写入带注释的配置。** 不再把带注释的 OpenCode 配置标成失败。
- **应用图标不再套双层圆角。** 母版铺满画布，圆角交给 macOS 26 系统裁剪。
- **智能体终态卡按钮居中。** 操作按钮与图标、标题同一中轴。
- **警告图标与首行文字对齐。**
- **Homebrew 安装的智能体在 Linux 上更新时不再顺带用 npm 再装一份。** 对应 brew 步骤不可用时只走该安装源的回退，不会把 npm 全局安装加进计划。

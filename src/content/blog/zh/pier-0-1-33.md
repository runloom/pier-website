Pier 0.1.33（2026-08-28）把项目配置和手机查看收进产品，并收紧阅读、画布和 Git 变更体验。

## 项目配置能记住

设置 → 项目里，可以为仓库保存 MCP 等命令行配置。下次打开这个项目就能用，不必每次重配。

## 同一网络的手机也能看

设置里配对手机后，在同一局域网可以查看会话、文件和变更。

## HTML / SVG 预览

文件面板能预览 HTML 和 SVG，缩放操作和图片预览一样。

## Markdown 阅读宽度更稳

正文用固定的舒适宽度，不再跟着字体或预览缩放忽宽忽窄。长路径在栏内换行，靠左对齐。

## 画布接手旧的工作台面板

画布现在用插件提供的数据和动作来组合界面。新建工作台命令和旧的工作台面板已经去掉；账号的添加、删除和登录仍在设置页。Pier 作为本地开发工作台，这一点没有变。

## 安装包更小

各尺寸图标从同一份矢量图生成。改用系统字体，不再打包额外中文字体，安装包大约小了 31MB。

## 终端更稳，Git 变更更好跟

长时间开着的终端不再闪烁。焦点在终端时，查找等快捷键先交给终端。看 Git 变更时，搜索、跳转和评论更好跟。重启 Pier 后，没结束的会话仍会显示并接上。

升级后打开项目即可使用。完整变更见 [CHANGELOG](https://github.com/runloom/pier/blob/main/CHANGELOG.md)。

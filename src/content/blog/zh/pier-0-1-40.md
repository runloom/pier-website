Pier 0.1.40（2026-09-06）发布。本版更新内容如下。

## 新增

- **终端支持原生滚动到底。** `Cmd+↓` / `Cmd+End` 可在无 shell 提示符标记的界面里回到底部。
- **Files 本地 diff 速览。** 从源码 gutter 与 Markdown 变更色条可直接打开当前文档的局部修改预览。

## 变更

- **终端状态栏 git 芯片标题统一用全大写 GIT。**
- **多智能体启动命令补充 yolo 直启参数。** 覆盖 Droid、OpenCode、Kilo、Mimo Code 与 OMP。

## 修复

- **文件树切换更改后不再滚动冲突与抖动。**
- **Grok 账号不再出现邮箱溢出与会员状态残留。**
- **任务引导改为连接 Linear / Jira，而不是粘贴不透明令牌。**
- **审查树拖到最大宽度时不再被分隔把手挤窄。**

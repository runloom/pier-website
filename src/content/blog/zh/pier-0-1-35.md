Pier 0.1.35（2026-08-31）发布。本版更新内容如下。

## 新增

- **审查里能打开项目目录。** 变更树、对比和审查标签右键可打开 Files 的项目目录标签（只含目录树），定位到这次审查的 git 根；不抢审查主点击，顶栏也不加芯片。
- **提交选择器支持连续范围。** Changes 顶栏「提交」：勾一个立刻审这一份；再勾另一个以刚才那次为原点，审连续净变化。只点左侧勾选列。
- **macOS 系统权限说明与恢复入口。** 访问桌面、文稿、下载时系统会说明用途；被拒绝后文件树和恢复的标签会指向「隐私与安全性 › 文件和文件夹」，而不是一串错误码。

## 变更

- **产品前门先讲场面。** 根 README 和官网：几个终端谁在等你；文件、编辑、Git 在同一窗口。Canvas 页面可用，看板和运行图还在做。不宣称已经替代 VS Code。插件写当前范围，不把第三方市场写成永远不做。
- **Canvas 模板改成示范级。** 阅读流、画板流和看板模板打开即可对照两种画布模式，不再是空壳。
- **项目记忆覆盖更多 MCP 客户端。** 官方 MCP 发现面里的客户端都会登记项目记忆（含 Grok）。
- **标题栏智能体计数可悬停看说明。** 与通知铃铛一样，悬停显示列表名称和快捷键。
- **Markdown 图预览跟阅读纸面。** 图表落在阅读纸上；宽屏版心为默认。
- **文件与 git 审查共用树宽。** 两边侧栏宽度一起记、一起拖。

## 修复

- **确认提交时显示进行中。** 点提交后按钮进入等待，避免连点。
- **审查顶栏提交只保留文字。** 去掉按钮上的图标。
- **把面板移到另一窗口后聚焦目标窗。**
- **面板标签两侧悬停不再露出刻度。**
- **智能体回合结束不再被旧日志带偏。** 按原生回合身份记账，只有新工具开始才重新打开回合；丢掉图形启动器泄漏的钩子事件。
- **智能体名称显示正确。** Crush、Kilo Code 不再用错标签。
- **pi / kimi 能按原生会话接着聊。**

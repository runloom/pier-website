Pier 0.1.47（2026-10-19）发布。本版更新内容如下。

## 新增

- **`.mermaid` / `.mmd` 文件直接看图表。** 文件面板打开这类文件时默认显示渲染后的图表，可随时切回源码；渲染、纸面配色与全屏查看沿用 Markdown 里的 Mermaid 围栏，语法写错时给出可重试的失败提示。

## 修复

- **终端里 ⌘C / ⌘V / ⌘A 恢复生效。** 应用菜单的复制/粘贴/全选角色会把这些组合派发给当前 first responder，而原生终端的 first responder 由渲染层状态异步移交；交接完成前菜单会先消费 ⌘C 并复制空的 web 选区，终端选区始终没被复制。现在终端拥有键盘时由事件路由先按键盘归属执行对应剪贴板动作，不再依赖 first responder 时机；web 侧快捷键与菜单行为保持不变。

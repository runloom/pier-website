Pier 0.1.37（2026-09-03）をリリースしました。本バージョンの更新内容は次のとおりです。

## 新機能

- **Markdown とレビューで SVG をプレビューできるようになりました。** 仕様に沿った SVG は画像として開かれ、バイナリ表示にはフォールバックしません。
- **図表プレビューには同じ公式エンジンを使用します。** Markdown、全画面表示、キャンバスでテーマとソースの整形を共有し、ズームイン／アウト時にはビットマップで負荷を軽減します。

## 変更

- **設定の MCP ページをエージェント横断の一覧に変更しました。** Pier 管理 / プロジェクト内 / ユーザー設定でグループ化し、誰が利用できるか、誰がまだ利用できないかを、ローカルプロセスかリモートかとともに示します。エージェント名を表示することで、Grok の X アイコンを失敗と読み違えないようにします。リポジトリ内のプロジェクトでは `pier-memory` がプロジェクトメモリを開きます。Pier は引き続きこれらのファイルを変更せず、サーバーも起動しません。
- **ホームディレクトリの MCP 設定を開いても空白ページにならなくなりました。** ワークスペース外のファイルは実際のパスと内容が表示され、現在のプロジェクトの `config.yaml` として扱われることはありません。
- **新規作成メニューの項目順が安定しました。** フッターの「エージェントを管理…」はポップオーバーに固定され、コマンド検索とスキル検索も同じ並び順で実行されます。
- **ファイルパネルの画像プレビューで、全画面タイトルバー用の余白を確保しないようになりました。**
- **モバイル Web シェルをリモートコックピットスタイルに変更しました。** セッション、レビュー、ホストの各エントリをコックピットの情報アーキテクチャに合わせて再配置しました。

## 修正

- **アプリを長時間開いたままでも、メモリ使用量が増え続けなくなりました。** キャンバスとブロックのホットアップデートでは以前の実行環境を破棄し、使用量リクエストではチャレンジごとに非表示ウィンドウを開かなくなりました。
- **表示中の複数のターミナルが繰り返し再挿入されないようになりました。**
- **ターミナルのスクロールバーのクリップ位置が、システムの計算式どおりに揃うようになりました。**
- **タブを新しいウィンドウに切り離す際、ウォームアップウィンドウを既存の移動先と見なさないようになりました。**
- **キャンバスのソース内にある `pier/canvas` モジュールを言語サービスで解析できるようになりました。**

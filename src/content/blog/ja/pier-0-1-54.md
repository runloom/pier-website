Pier 0.1.54（2026-10-27）をリリースしました。本バージョンの更新内容は以下のとおりです。

## 修正

- **Markdown 内の Mermaid 図が、レンダリングできないと誤って報告されなくなりました。** Mermaid は HTML シリアライズされた断片を出力しますが、以前のパーサーは XML として読み込んでいたため、ブラウザが補完した `<br>` がフォーマットエラーと見なされていました。現在は HTML として解析されるため、有効な図は正常に表示されます。
- **ファイルツリー内の Git 無視項目が再び淡色表示されるようになりました。** 「無視項目を表示」をオンにした後、以前は無視インデックスが読み込まれなくなっていたため、無視項目と通常ファイルの区別がつきませんでした。現在は無視項目が淡色表示のままになり、Git ステータスマーカーも表示されます。

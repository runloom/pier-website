Pier 0.1.40（2026-09-06）リリース。本バージョンの更新内容は以下のとおりです。

## 新機能

- **ターミナルでネイティブな最下部スクロールに対応。** `Cmd+↓` / `Cmd+End` で、シェルのプロンプトマーカーがないインターフェースでも最下部に戻れます。
- **Files のローカル diff クイックビュー。** ソースコードのガターや Markdown の変更色バーから、現在のドキュメントの部分的な変更プレビューを直接開けます。

## 変更

- **ターミナルのステータスバーにある git チップのタイトルを、すべて大文字の GIT で統一。**
- **マルチエージェント起動コマンドに、yolo の直接起動パラメーターを追加。** Droid、OpenCode、Kilo、Mimo Code、OMP をカバー。

## 修正

- **ファイルツリーで変更を切り替えた際に、スクロールの競合やガタつきが発生しなくなった。**
- **Grok アカウントで、メールアドレスのはみ出しやメンバーシップ状態の残存が発生しないよう修正。**
- **タスクガイドを、不透明なトークンを貼り付けるのではなく、Linear / Jira に接続する方法に変更。**
- **レビューツリーを最大幅までドラッグしても、分割ハンドルによって幅が狭められないよう修正。**

Pier 0.1.34（2026-08-30）をリリースしました。このバージョンの更新内容は次のとおりです。

## 新機能

- **設定で候補版の受信を有効にできます。** 設定 → 更新に「候補版を受け取る」トグル（デフォルト: オフ）を追加しました。オンにすると正式リリース前に候補版を受け取れます。正式版がリリースされると自動的に置き換わります。一般ユーザーには影響ありません。
- **パネルを他のウィンドウに移動できます。** タブを右クリック: ウィンドウが2つの場合は直接もう一方のウィンドウへ移動し、複数ある場合はサブメニューから移動先を選択します。
- **コマンドラインでディレクトリとファイルを開けます。** `pier .` やパスの短縮形で既存のワークスペースにフォーカスするか、エディタでファイルを開きます（`:行[:列]` に対応）。
- **レビューページからコミットを確定できます。** コマンドと未コミットレビューは同じ入り口を使い、確認カードで現在の変更をコミットします。チェックボックスは前回の選択を記憶せず、「コミット後にプッシュ」も書き戻しません。
- **プロジェクトタスクとファイルアイコンがより充実。** Dart / CMake / Python / Go / Maven / Gradle などのプロジェクトファイルを認識し、内蔵タスクを提供します。Dart はワークスペースの FVM SDK を優先します。

## 変更

- **ホストのリリースに候補版のフローを追加。** 通常リリースではまず `vX.Y.Z-rc.N` をタグ付けします（GitHub prerelease。Latest にはせず、ブログも公開しません）。観察期間の後に正式版 `vX.Y.Z` へ昇格します。明示的に「直接リリース」を実行すると候補版をスキップできます。詳細は `docs/release.md` と候補版のゴールドスタンダード仕様を参照してください。
- **関連パネルが現在のタブの直後に挿入されます。** 新しく開いた関連パネルは現在のタブの右側に配置されます。タブ間の隙間、余白、ホバー時の背景はリストと統一されます。
- **エージェント CLI のバージョン検出が信頼できるリモートを参照。** Homebrew コアのフォーミュラは formulae.brew.sh を参照し、古いローカルインデックスを最新とみなさなくなりました。既知のインストール元では、エコシステムをまたいで最新版を取得したり更新計画を立てたりしません。
- **Kimi Code のみを管理対象に。** PATH 上の古い Python `kimi-cli` を同一製品と見なして更新することはありません。
- **プロジェクトメモリはリポジトリのファイルを変更する必要がありません。** プロジェクトメモリを有効にしたリポジトリでは、起動時にホストが説明をエージェントに渡します。
- **ウィンドウリストのタイトルに最下層ディレクトリ名が重複しなくなりました。** メインタイトルはワークスペースの最下層ディレクトリ名を使用し、右側には異なる git ブランチまたはアクティブなファイルだけを表示します。

## 修正

- **分割ビューのドラッグでターミナルが隠れなくなりました。** 分割バーやフローティング層のリサイズバーをドラッグしても、ターミナルは表示されたままアンカーに合わせてサイズが変わります。ウィンドウの端をドラッグするときだけ不可視のプレースホルダーを使用します。
- **ダイアログのオーバーレイがタイトルバーを覆うように。** ポップアップを開くとカスタムタイトルバーも一緒に暗くなります。オーバーレイをクリックして閉じられるポップアップは、タイトルバーをクリックしても閉じられます。
- **リフレッシュ後、実行中のターミナルを誤って閉じなくなりました。** セッションに再接続する際に識別子を固定します。レイアウトが準備できていないときは、空のリストで稼働中のターミナルを閉じません。
- **全画面プレビューが一瞬ちらつかなくなり、画像コピーが使えるようになりました。** ライトボックスは既存のプレビュー画像を再利用し、コピーは描画済みの画像から PNG を生成します。
- **エージェントに渡すコメントがよりクリーンに。** 位置とコメント本文のみを送信し、UI ラベルや抜粋は添付しなくなりました。
- **拡張入力メニューが開閉状態に応じて「開く」または「閉じる」を表示。** 右クリックメニューとコマンドパレットで「切り替え」と表示されなくなりました。
- **複数ファイルレビューの折りたたみリストで区切り線が見えるように。** 区切り線をファイルカード上に描画するようになり、ファイルヘッダーに隠れません。
- **OpenCode のプロジェクトメモリがコメント付き設定に書き込まれます。** コメント付きの OpenCode 設定を失敗と判定しなくなりました。
- **アプリアイコンが二重の角丸にならないように。** マスターをキャンバス全体に敷き詰め、角丸は macOS 26 のシステムによる切り抜きに任せます。
- **エージェント終了状態カードのボタンを中央揃えに。** 操作ボタンがアイコン・タイトルと同じ中心軸に配置されます。
- **警告アイコンが最初の行の文字と揃います。**
- **Homebrew でインストールしたエージェントを Linux で更新する際、npm で追加インストールされなくなりました。** 対応する brew の手順が利用できない場合は、そのインストール元のフォールバックのみを使用し、npm のグローバルインストールを計画に追加しません。

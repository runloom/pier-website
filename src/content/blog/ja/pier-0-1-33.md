Pier 0.1.33（2026-08-28）は、プロジェクト設定とスマホからの閲覧を製品に取り込み、閲覧・キャンバス・レビューの体験を引き締めました。

## プロジェクト記憶

設定 → プロジェクトで、リポジトリに管理対象のエージェント設定（MCP など）を登録できます。次回そのプロジェクトを開けばそのまま使え、毎回やり直す必要はありません。

## 同一ネットワークのスマホ

設定でスマホをペアリングすると、同じ LAN 上でセッション、ファイル、変更を確認できます。

## HTML / SVG プレビュー

ファイルパネルで HTML と SVG をプレビューでき、拡大縮小は画像プレビューと同じ操作です。

## Markdown の快適な読み欄

本文の欄幅はルート字号の固定の快適幅になり、ドキュメントフォントやプレビュー倍率に追随して伸び縮みしません。長いパスは欄内で折り返し、左揃えで、両端揃えにはしません。

## キャンバスと Workbench

キャンバスはプラグインが提供するデータとアクションで組み立てます。新規 Workbench コマンドと旧 Workbench パネルは削除しました。アカウントの追加・削除・ログインはこれまでどおり設定ページです。

## アプリアイコンとインストーラ

各サイズのアイコンは同一のベクター原版から縮小します。システムフォントを優先し、追加の中国語フォントを同梱しなくなったため、インストーラは約 31MB 小さくなりました。

## より安定したターミナルとレビュー

長時間利用時のチラつきを切り、フォーカスがターミナルにあるときは検索などのショートカットをターミナルへ優先します。git レビューの検索、スケルトン、クリックジャンプ、コメント位置も追いやすくなりました。Pier を再起動したあとも、終了していないエージェントセッションは表示され、続行できます。

アップデート後、プロジェクトを開けば使えます。変更の全体は [CHANGELOG](https://github.com/runloom/pier/blob/main/CHANGELOG.md) を参照してください。

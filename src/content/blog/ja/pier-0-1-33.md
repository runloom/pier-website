Pier 0.1.33（2026-08-28）は、プロジェクト設定とスマホからの閲覧を製品に取り込み、閲覧・キャンバス・Git 確認を引き締めました。

## プロジェクト設定を覚える

設定 → プロジェクトで、リポジトリに MCP などのコマンドライン設定を保存できます。次回そのプロジェクトを開けばそのまま使え、毎回やり直す必要はありません。

## 同じネットのスマホからも見られる

設定でスマホをペアリングすると、同じ LAN 上でセッション、ファイル、変更を確認できます。

## HTML / SVG プレビュー

ファイルパネルで HTML と SVG をプレビューでき、拡大縮小は画像プレビューと同じ操作です。

## Markdown の読み幅が安定

本文は固定の読みやすい幅になり、フォントやプレビュー倍率で伸び縮みしません。長いパスは欄内で折り返し、左揃えです。

## キャンバスが旧 Workbench パネルを引き継ぐ

キャンバスはプラグインが提供するデータとアクションで画面を組み立てます。新規 Workbench コマンドと旧 Workbench パネルは削除しました。アカウントの追加・削除・ログインはこれまでどおり設定ページです。Pier がローカルの開発ワークベンチであることは変わっていません。

## インストーラが小さくなった

各サイズのアイコンは同一のベクター原版から作ります。システムフォントを優先し、追加の中国語フォントを同梱しなくなったため、インストーラは約 31MB 小さくなりました。

## ターミナルが安定し、Git 変更が追いやすい

長時間開いたターミナルがちらつかなくなりました。フォーカスがターミナルにあるときは、検索などのショートカットをターミナルへ優先します。Git 変更の検索、ジャンプ、コメントも追いやすくなりました。Pier を再起動したあとも、終わっていないセッションは表示され、続行できます。

アップデート後、プロジェクトを開けば使えます。変更の全体は [CHANGELOG](https://github.com/runloom/pier/blob/main/CHANGELOG.md) を参照してください。

Pier 0.1.36（2026-09-02）リリース。本バージョンの更新内容は次のとおりです。

## 追加

- **タスク追跡パネル。** 公式プラグインが GitHub、Linear、Jira のタスクをプロジェクトパネルとキャンバス上に配置できるようになりました。Linear / Jira はワークフローごとに列分けされ、ドラッグ＆ドロップの順序を記憶します。GitHub は引き続き担当者ごとにまとめられます。
- **スマホがローカルネットワーク外から PC に接続可能に。** ペアリング後はランデブークラウドとプッシュ通知経由で Mac を起こせるため、PC と同じネットワークセグメントにいる必要はありません。
- **タブをウィンドウの外へドラッグ。** Pier の外にドラッグすると、元のタブはすぐにしまわれ、対象ウィンドウはウォームアップ後に表示されます。元に戻ったり、いったん空白のまま待たされたりすることはありません。
- **競合レビューと通常の差分が同じビューに。** 未変更の行は展開できます。ファイルレベルの競合では、ワークスペースの本文と解決ボタンが引き続き表示されます。
- **Markdown プレビューの左側に HEAD との差分バーを表示。** 細いガターがソースレビューに揃い、コメントやアウトラインを遮りません。
- **Markdown テーブルの列幅をドラッグで変更可能にし、ヘッダーに基づいて記憶。** セルを編集しても列幅は保持されます。ドラッグを離したときに保存され、Escape でキャンセル。プレビューの右クリックでソースへ戻れます。
- **キャンバスは表示位置を記憶。** パンやズーム後はワールド座標の中心で復元されます。画像、チャート、Markdown、キャンバスは同じズームコントロールを共有します。
- **パスのコピーが独立したメニュー項目に。** ファイルタブ、ツリー、検索でパスまたは相対パスをコピーでき、対応するショートカットキーも表示されます。エディターとレビュー差分では、引き続き範囲付きパスをコピーします。
- **右クリックメニューはサーフェスに応じて主操作を配置。** レビューツリーではステージ操作が優先されます。ターミナルの検索とクリアは、コピー＆ペーストと最初のグループを争いません。
- **エディターで ⌘D を押すと次の一致箇所も選択。** VS Code と同じ動作です。画面分割のショートカットはターミナルのみに割り当てられます。
- **ルートの README が中英日韓に対応。** GitHub でのデフォルトは引き続き簡体字中国語です。上部で English、日本語、한국어 に切り替えられます。
- **CLI ユーザーマニュアルが中英日韓に対応。** GitHub のエントリー `.pier/canvases/pier-cli-user-manual/README.md` のデフォルトは引き続き簡体字中国語です。上部で English、日本語、한국어 に切り替えられます。アプリ内の Canvas は引き続き中国語です。

## 変更

- **`/pier-canvas` はシェル未指定時、エージェントが skill から推論します。** ホストは `locale=` のみを注入し、キーワードで `mode` / `recipe` / `content` を付けません。UI案はキャンバスへ、決定稿は読み取りフローへ送られます。明示的なパラメーターが引き続き優先され、`/pier-canvas` だけを入力した場合は従来どおり決定稿になります。
- **設定のプラグイン行と言語サービスがよりコンパクトに。** プラグイン行は名前と操作のみを表示します。言語サービスは縦型リストになり、次にインストールへ進めます。
- **コマンドパレットと設定の git グループを GIT 表記に。** プラグイン名、設定タイトル、コマンドグループ、コマンドプレフィックスを統一しました。

## 修正

- **キャンバスでコンパイルに失敗すると空の状態を表示するように。** ファイルを変更したあとのホットアップデートが失敗しても、警告を以前のキャンバスに重ねて表示しません。プレビュー可能なままの警告、保存失敗、ワークスペース外のパス、部分的なレビュー結果は、パネル上端に沿った1つの通知にまとめられます。
- **明るい背景上のフレームタイトルが読みやすくなりました。** フレームの名前と説明は背景の明るさに応じた文字色になり、ホストのダークテーマによる白文字が使われません。フレーム内の製品UIは引き続きアプリのテーマに従います。
- **ファイル・git・ターミナルのリアルタイム更新が失われません。** ディレクトリ更新が集中しても追従できます。ターミナルの状態転送がキューで取りこぼされません。
- **フォルダーが後からリポジトリになった場合、ステータスバーに git 情報が補完表示されます。**
- **レビュー内でタスクを実行しても現在のパネルを奪いません。** バックグラウンドで実行され、進行状況は元のパネルに重ねて表示されます。
- **ツールチップの小さな三角形が点に縮まなくなりました。**
- **コマンドリストに項目が1つしかない場合、グループ見出しが表示されません。** コマンドパレットの空状態では、よく使う項目が「最近」にまとめられます。
- **絶対パスの貼り付けが現在のディレクトリに連結されません。** VS Code / Zed と同じ動作です。
- **中国語IMEでEnterキーを押しても候補が文字化けしなくなりました。**
- **ターミナルでのドラッグ選択がシステムのクリップボードを上書きしません。** ドラッグ選択はプライベートクリップボードに入ります。コピー、貼り付け、全選択はキーボードショートカットの制御に飲み込まれません。
- **ウィンドウをまたいでコピーしたあとの貼り付けが空にならなくなりました。**
- **システムの外観変更がウィンドウに即時反映されます。**
- **パネルグループを閉じたあと、フォーカスは最後に使っていたグループに留まります。** 左上にある最初のグループへ移動しません。
- **Kimi が空のターンで失敗しても状態を復元できるように。** 認証リクエストは待機状態に入ります。
- **エージェント更新のタイムアウト時に、npm によるプロセス終了の原文メッセージが表示されません。**
- **プロジェクトメモリが、書き込み済みの TOML MCP 項目を誤って「部分的に接続」と報告しないように。**
- **スマホの戻るキーで元のセッションに戻ります。** 複数ウィンドウで誤ったターミナルにバインドされません。ワークベンチのターミナルタイトルはデスクトップのタブ短縮名と一致します。
- **デバイスが取り消されるとスマホに直接通知されます。** 一般的な切断として表示されません。同じマシンのLANエントリとランデブークラウドエントリは1行にまとめられます。

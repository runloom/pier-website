Pier 0.1.54(2026-10-27)가 출시되었습니다. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 수정

- **Markdown의 Mermaid 다이어그램이 더 이상 렌더링할 수 없다고 잘못 보고되지 않습니다.** Mermaid는 HTML 직렬화된 스니펫을 출력하는데, 이전 파서는 이를 XML로 읽었기 때문에 브라우저가 채워 넣은 `<br>`가 형식 오류로 처리되었습니다. 이제 HTML로 파싱하므로 유효한 다이어그램이 정상적으로 표시됩니다.
- **파일 트리의 Git 무시 항목이 다시 흐리게 표시됩니다.** '무시 항목 표시'를 켜도 이전에는 무시 인덱스를 더 이상 로드하지 않아 무시 항목과 일반 파일을 구분할 수 없었습니다. 이제 무시 항목은 흐리게 유지되고 Git 상태 마커가 함께 표시됩니다.

Pier 0.1.40(2026-09-06) 출시. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 새로운 기능

- **터미널에서 기본(네이티브) 스크롤 맨 아래 이동을 지원합니다.** `Cmd+↓` / `Cmd+End`로 셸 프롬프트 표시가 없는 화면에서도 맨 아래로 돌아갈 수 있습니다.
- **Files 로컬 diff 빠른 보기.** 소스 코드 거터 및 Markdown 변경 색상 막대에서 현재 문서의 부분 변경 미리보기를 바로 열 수 있습니다.

## 변경 사항

- **터미널 상태 표시줄의 git 칩 제목을 모두 대문자 GIT로 통일했습니다.**
- **멀티 에이전트 시작 명령에 yolo 직접 실행 매개변수를 추가했습니다.** Droid, OpenCode, Kilo, Mimo Code 및 OMP를 지원합니다.

## 수정

- **파일 트리에서 변경 사항을 전환한 후 스크롤 충돌이나 흔들림이 더 이상 발생하지 않습니다.**
- **Grok 계정에 이메일이 넘치거나 멤버십 상태가 남아 표시되지 않습니다.**
- **작업 안내가 불투명한 토큰을 붙여넣는 대신 Linear / Jira에 연결하도록 변경되었습니다.**
- **리뷰 트리를 최대 너비로 끌어도 분할 핸들 때문에 좁아지지 않습니다.**

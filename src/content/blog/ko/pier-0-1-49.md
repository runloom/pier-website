Pier 0.1.49(2026-10-21) 릴리스. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 수정

- **대규모 변경 리뷰에서 diff 하이라이트를 더 이상 렌더러 메인 스레드로 폴백하지 않습니다.** 워커가 시간 초과되거나 사용할 수 없을 때, 파일이 16개를 초과하거나 패치가 256KB를 초과하는 리뷰 화면은 워커를 유지합니다(최대 30초 대기). 그래도 실패하면 재시도 가능한 오류를 표시하고, 더 이상 인라인으로 재작업해 UI를 멈추게 하지 않습니다. 응답 없음 진단에는 렌더러 CPU / 메모리, 크래시 전 `sample` 스택, diff 워커 실패 브레드크럼이 추가되었습니다.

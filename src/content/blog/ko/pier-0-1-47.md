Pier 0.1.47(2026-10-19) 릴리스. 이번 버전 업데이트 내용은 다음과 같습니다.

## 추가

- **`.mermaid` / `.mmd` 파일에서 다이어그램을 바로 확인할 수 있습니다.** 파일 패널에서 이러한 파일을 열면 기본적으로 렌더링된 다이어그램이 표시되며, 언제든 소스로 전환할 수 있습니다. 렌더링, 종이 색상 구성, 전체 화면 보기는 Markdown의 Mermaid 코드 펜스 설정을 그대로 따르며, 구문이 잘못된 경우 다시 시도할 수 있는 실패 안내를 표시합니다.

## 수정

- **터미널에서 ⌘C / ⌘V / ⌘A가 다시 동작합니다.** 앱 메뉴의 복사/붙여넣기/모두 선택 역할은 이 조합을 현재 first responder로 전달하지만, 네이티브 터미널의 first responder는 렌더러 계층 상태에 따라 비동기적으로 넘겨집니다. 전환이 완료되기 전에 메뉴가 먼저 ⌘C를 처리해 빈 웹 선택 영역을 복사했고, 터미널 선택 영역은 계속 복사되지 않았습니다. 이제 터미널이 키보드를 소유하고 있을 때는 이벤트 라우팅이 키보드 소유권에 따라 해당 클립보드 동작을 먼저 수행하며, 더 이상 first responder 시점에 의존하지 않습니다. 웹 쪽 단축키와 메뉴 동작은 그대로 유지됩니다.

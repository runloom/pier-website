Pier 0.1.37(2026-09-03)이 릴리스되었습니다. 이번 버전 업데이트 내용은 다음과 같습니다.

## 새로운 기능

- **Markdown 및 리뷰에서 SVG를 미리 볼 수 있습니다.** 올바른 형식의 SVG는 이미지로 열리며, 더 이상 바이너리 안내로 표시되지 않습니다.
- **차트 미리보기가 동일한 공식 엔진을 사용합니다.** Markdown, 전체 화면, 캔버스가 테마와 소스 정리를 공유하며, 확대·축소 시 비트맵을 사용해 부하를 줄입니다.

## 변경 사항

- **설정의 MCP 페이지가 에이전트 전반 목록으로 변경됩니다.** Pier 호스팅 / 프로젝트 내 / 사용자 구성별로 그룹화되고, 누가 사용할 수 있는지, 아직 사용할 수 없는지, 로컬 프로세스인지 원격인지 표시합니다. 에이전트에 이름이 표시되어 Grok의 X 아이콘을 실패로 오인하지 않습니다. `pier-memory`는 저장소 프로젝트에서 프로젝트 메모리를 엽니다. Pier는 여전히 해당 파일을 수정하거나 서버를 시작하지 않습니다.
- **홈 디렉터리의 MCP 구성 파일을 열어도 빈 페이지가 표시되지 않습니다.** 작업 영역 밖의 파일은 실제 경로와 내용이 표시되며, 현재 프로젝트의 `config.yaml`로 위장하지 않습니다.
- **새로 만들기 메뉴의 디렉터리 구성이 안정적으로 유지됩니다.** 하단의 "에이전트 관리…"가 팝업에 붙어 있으며, 명령 및 스킬 검색은 동일한 정렬 순서를 사용합니다.
- **파일 패널의 이미지 미리보기에서 전체 화면 제목 표시줄 공간이 더 이상 예약되지 않습니다.**
- **모바일 웹 셸이 원격 조종석 스타일로 변경됩니다.** 세션, 리뷰, 호스트 진입점이 조종석 정보 구조에 따라 재배치됩니다.

## 버그 수정

- **앱을 오랫동안 켜 둔 후에도 메모리가 계속 증가하지 않습니다.** 캔버스와 블록 핫 업데이트가 이전 실행 환경을 완전히 해체하며, 사용량 요청이 더 이상 각 챌린지마다 숨겨진 창을 열지 않습니다.
- **여러 개의 표시된 터미널이 반복적으로 다시 연결되지 않습니다.**
- **터미널 스크롤바 잘림이 시스템 공식에 맞게 정렬됩니다.**
- **탭을 새 창으로 떼어낼 때 워밍업 창을 기존 대상으로 취급하지 않습니다.**
- **캔버스 소스의 `pier/canvas` 모듈이 언어 서비스에서 해석될 수 있습니다.**

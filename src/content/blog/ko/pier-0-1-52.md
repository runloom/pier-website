Pier 0.1.52(2026-10-26)가 릴리스되었습니다. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 변경

- **멈추기 전 메인 스레드 블로킹이 기록됩니다.** 200ms를 초과하는 메인 스레드 작업은 독립적인 브레드크럼으로 즉시 디스크에 기록됩니다. 연속으로 여러 개가 발생하면 최신 몇 개만 남기고 개수를 합산해, 멈췄을 때 "누가 메인 스레드를 점유했는지" 볼 수 있습니다. 각 기록에는 메인 측에서 읽은 UI CPU와 메모리도 함께 포함되어, 멈추기 전 리소스 사용량이 올라가고 있었는지 판단할 수 있습니다.
- **무응답 진단의 샘플링 예산이 완화되었습니다.** 샘플링 시간은 1초에서 3초로, 총 대기 시간은 2초에서 6초로 늘어났습니다. 이전에는 프로세스가 GC에 갇혀 있을 때 샘플러가 붙기도 전에 종료되어 스택 파일이 비어 있었습니다. 이제 샘플러의 오류 출력은 별도로 기록되어 "샘플링이 너무 느림"과 "샘플링 권한 없음"을 구분하기 쉬워졌습니다.

## 수정

- **`⌘W`는 현재 작업 중인 탭을 닫습니다.** 키보드 포커스가 특정 탭에 있을 때 `⌘W`는 옆에 선택된 탭이 아니라 해당 탭을 닫습니다. 명령 팔레트, 설정, 확인 팝업 등 차단형 오버레이가 열려 있을 때 `⌘W`는 오버레이 뒤의 패널이나 창을 닫지 않습니다. 키보드 포커스를 이동시키지 않는 컨트롤을 클릭한 뒤에도 `⌘W`는 이전 패널을 닫지 않습니다.
- **샘플링 구간 내에서 먼저 복구되었다가 다시 멈춘 창도 복구됩니다.** 이전에는 "복구됨"을 한 번이라도 받으면 이번 무응답 처리가 끝난 것으로 간주해, 샘플링 중 다시 멈춘 창이 동결 상태로 남았습니다. 이제는 샘플링이 끝나는 시점에 여전히 무응답인지 여부로 결정합니다. 같은 창에서 여러 번 무응답이 발생하는 경우도 순차 처리하도록 바뀌어, 더 이상 병렬로 샘플링해 같은 사고를 두 구간으로 나누지 않습니다.
- **UI가 멈췄을 때 존재하지 않는 스택 파일을 성공으로 처리하지 않습니다.** 샘플러는 파일을 쓸 수 없을 때도 정상 종료되며, 이전에는 이것이 "스택 저장됨"으로 잘못 기록되었습니다. 이제는 디스크에 파일이 실제로 있는지를 기준으로 하며, 쓸 수 없으면 실패로 그대로 기록합니다.

Pier 0.1.33(2026-08-28)은 프로젝트 설정과 휴대폰 조회를 제품에 담고, 읽기·캔버스·검토 경험을 다듬었습니다.

## 프로젝트 기억

설정 → 프로젝트에서 저장소에 관리되는 에이전트 구성(예: MCP)을 등록할 수 있습니다. 다음에 그 프로젝트를 열면 바로 사용할 수 있어 매번 다시 맞출 필요가 없습니다.

## 같은 네트워크의 휴대폰

설정에서 휴대폰을 페어링하면 같은 LAN에서 세션, 파일, 변경을 볼 수 있습니다.

## HTML / SVG 미리보기

파일 패널에서 HTML과 SVG를 미리볼 수 있으며, 확대·축소는 이미지 미리보기와 같습니다.

## Markdown 편안한 읽기 단

본문 단 너비는 루트 글자 크기 기준의 고정된 편안한 폭이며, 문서 글꼴이나 미리보기 배율에 따라 늘어나지 않습니다. 긴 경로는 단 안에서 줄바꿈되고, 왼쪽 정렬이며 양끝 정렬을 쓰지 않습니다.

## 캔버스와 Workbench

캔버스는 플러그인이 제공하는 데이터와 동작으로 조합합니다. 새 Workbench 명령과 이전 Workbench 패널은 제거되었습니다. 계정 추가·삭제·로그인은 여전히 설정 페이지에서 합니다.

## 앱 아이콘과 설치 패키지

모든 크기 아이콘은 하나의 벡터 원본에서 축소합니다. 시스템 글꼴을 우선하고 추가 중국어 글꼴을 묶지 않아 설치 패키지가 약 31MB 작아졌습니다.

## 더 안정적인 터미널과 검토

오래 쓸 때 깜빡이던 터미널을 끊었고, 포커스가 터미널에 있으면 찾기 등 단축키를 터미널에 먼저 줍니다. git 검토의 검색, 로딩 자리, 클릭 이동, 댓글 위치도 따라가기 쉽습니다. Pier를 다시 시작한 뒤에도 끝나지 않은 에이전트 세션이 보이고 이어서 쓸 수 있습니다.

업데이트한 뒤 프로젝트를 열면 됩니다. 전체 변경 기록은 [CHANGELOG](https://github.com/runloom/pier/blob/main/CHANGELOG.md)를 참고하세요.

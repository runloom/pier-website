Pier 0.1.33(2026-08-28)은 프로젝트 설정과 휴대폰 조회를 제품에 넣고, 읽기·캔버스·Git 확인을 다듬었습니다.

## 프로젝트 설정을 기억합니다

설정 → 프로젝트에서 저장소에 MCP 같은 명령줄 설정을 저장할 수 있습니다. 다음에 그 프로젝트를 열면 바로 쓸 수 있어 매번 다시 맞출 필요가 없습니다.

## 같은 네트워크의 휴대폰에서도 볼 수 있습니다

설정에서 휴대폰을 페어링하면 같은 LAN에서 세션, 파일, 변경을 볼 수 있습니다.

## HTML / SVG 미리보기

파일 패널에서 HTML과 SVG를 미리볼 수 있으며, 확대·축소는 이미지 미리보기와 같습니다.

## Markdown 읽기 폭이 안정적입니다

본문은 고정된 편안한 폭을 쓰고, 글꼴이나 미리보기 배율에 따라 늘어나지 않습니다. 긴 경로는 단 안에서 줄바꿈되고 왼쪽 정렬입니다.

## 캔버스가 예전 Workbench 패널을 이어받습니다

캔버스는 플러그인이 제공하는 데이터와 동작으로 화면을 조합합니다. 새 Workbench 명령과 이전 Workbench 패널은 제거되었습니다. 계정 추가·삭제·로그인은 여전히 설정 페이지에서 합니다. Pier가 로컬 개발 워크벤치라는 점은 바뀌지 않았습니다.

## 설치 패키지가 작아졌습니다

모든 크기 아이콘은 하나의 벡터 원본에서 만듭니다. 시스템 글꼴을 우선하고 추가 중국어 글꼴을 묶지 않아 설치 패키지가 약 31MB 작아졌습니다.

## 터미널이 더 안정적이고 Git 변경을 따라가기 쉽습니다

오래 연 터미널이 더 이상 깜빡이지 않습니다. 포커스가 터미널에 있으면 찾기 등 단축키를 터미널에 먼저 줍니다. Git 변경의 검색, 이동, 댓글도 따라가기 쉽습니다. Pier를 다시 시작한 뒤에도 끝나지 않은 세션이 보이고 이어서 쓸 수 있습니다.

업데이트한 뒤 프로젝트를 열면 됩니다. 전체 변경은 [CHANGELOG](https://github.com/runloom/pier/blob/main/CHANGELOG.md)를 보세요.

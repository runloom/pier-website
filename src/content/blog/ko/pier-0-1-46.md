Pier 0.1.46(2026-10-01)이 출시되었습니다. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 수정

- **충돌 검토에서 연속 다중 파일 목록이 복원되었습니다.** 일반 diff와 파일 헤더, 접기, 스크롤을 공유하며, 사이드바를 클릭하면 위치만 이동하고 더 이상 단일 파일 보기로 전환되지 않습니다. 좁은 창에서는 파일 이름을 우선 유지하고 상태 설명을 먼저 잘라냅니다. 파일 수준 해결 작업은 기존 컨텍스트 메뉴로 이동하고 새 버튼 바는 추가하지 않습니다. 버전 비교는 일반 diff 본문을 직접 재사용하여 중첩 레이아웃과 중복 여백을 제거합니다. 해결 후에는 해당 충돌만 제거됩니다.
- **충돌 본문이 실시간 상태와 동기화됩니다.** 테마를 전환하면 이미 표시된 본문이 업데이트됩니다. 변경 사항 수락과 컨텍스트 메뉴 해결은 쓰기 권한을 공유하며, 성공 또는 실패 후 변경 사항을 다시 읽은 뒤에만 작업을 다시 활성화하여 동시 쓰기를 방지합니다.
- **충돌 해결 시 외부 수정을 보호합니다.** 변경 사항 수락, 버전 선택, 스테이징은 모두 본문과 인덱스 식별자를 검증하며, 오래된 작업에는 다시 시도 안내를 표시하고 외부 편집을 덮어쓰지 않습니다. 변경 사항 수락은 안전한 원자적 쓰기를 사용하며, 충돌 삭제는 중복 스테이징으로 인해 더 이상 실패하지 않습니다. 실제 호스트 명령 선언을 보완하여, 읽을 수 없는 충돌이 있어도 전체 검토를 차단하지 않습니다.
- **충돌 해결의 경계 보호를 보강했습니다.** 인덱스에서 파일 권한이나 유형이 변경되면 오래된 작업을 거부합니다. 서브모듈과 큰 바이너리 파일에서도 버전을 올바르게 선택할 수 있으며, 긴 경로 충돌이 많아도 더 이상 검토 로드가 실패하지 않습니다. 임시로 작성된 파일이 교체되거나 변조되면 원본을 유지하고, 다른 프로세스가 교체한 파일을 삭제하지 않습니다.
- **에이전트의 오래된 완료 기록이 더 이상 새 질문을 방해하지 않습니다.** 새 질문을 제출하고 세션 기록 위치를 기다리는 동안, 과거 완료 메시지가 현재 세션을 먼저 완료 처리하지 않습니다. 다른 세션은 계속 정상적으로 업데이트되고, 새 완료 메시지는 평소대로 적용됩니다.

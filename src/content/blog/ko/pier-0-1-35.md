Pier 0.1.35(2026-08-31) 릴리즈입니다. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 새로운 기능

- **리뷰에서 프로젝트 디렉터리를 열 수 있습니다.** 변경 트리, 비교(diff), 리뷰 탭에서 마우스 오른쪽 클릭으로 Files의 프로젝트 디렉터리 탭(디렉터리 트리만 포함)을 열 수 있으며, 이번 리뷰의 git 루트로 이동합니다. 리뷰의 기본 클릭을 가로채지 않고 상단 바에 칩도 추가하지 않습니다.

- **커밋 선택기에서 연속 범위를 지원합니다.** Changes 상단 바의 '커밋': 하나를 체크하면 즉시 해당 커밋을 리뷰하고, 다른 하나를 체크하면 방금 그 커밋을 기준으로 연속된 순 변경분을 리뷰합니다. 왼쪽 체크박스 열만 클릭하면 됩니다.

- **macOS 시스템 권한 안내 및 복구 진입점.** 데스크톱, 문서, 다운로드에 접근할 때 시스템이 용도를 설명합니다. 거부된 후에는 파일 트리와 복구 탭이 오류 코드 대신 '개인정보 보호 및 보안 › 파일 및 폴더'를 가리킵니다.

## 변경 사항

- **제품 전면에서는 먼저 큰 그림을 설명합니다.** 루트 README와 공식 사이트: 여러 터미널 중 누가 기다리고 있는지, 파일·편집·Git이 같은 창에 있다는 점을 다룹니다. Canvas 페이지는 사용할 수 있으며, 칸반과 실행 그래프는 아직 작업 중입니다. 이미 VS Code를 대체한다고 주장하지 않습니다. 플러그인은 현재 범위를 명시하며, 타사 마켓플레이스를 '영원히 하지 않을 것'이라고 표현하지 않습니다.

- **Canvas 템플릿을 데모 수준으로 개선했습니다.** 읽기 플로우, 보드 플로우, 칸반 템플릿을 열면 두 캔버스 모드를 바로 비교할 수 있으며, 더 이상 빈 껍데기가 아닙니다.

- **프로젝트 메모리가 더 많은 MCP 클라이언트에 적용됩니다.** 공식 MCP 디스커버리 화면에 있는 모든 클라이언트가 프로젝트 메모리를 등록합니다(Grok 포함).

- **제목 표시줄의 에이전트 수에 마우스를 올리면 설명이 표시됩니다.** 알림 벨과 마찬가지로, 마우스를 올리면 목록 이름과 단축키가 나타납니다.

- **Markdown 다이어그램 미리보기가 읽기 용지에 맞춰집니다.** 다이어그램이 읽기 용지 위에 배치되며, 와이드스크린 본문 영역이 기본값입니다.

- **파일과 git 리뷰가 트리 너비를 공유합니다.** 양쪽 사이드바 너비를 함께 기억하고 함께 드래그합니다.

## 수정 사항

- **커밋 확인 시 진행 중 상태를 표시합니다.** 커밋을 누르면 버튼이 대기 상태가 되어 연타를 방지합니다.

- **리뷰 상단 바의 커밋 버튼에는 텍스트만 남깁니다.** 버튼의 아이콘을 제거했습니다.

- **패널을 다른 창으로 이동한 후 대상 창에 초점을 맞춥니다.**

- **패널 탭 양쪽에 마우스를 올려도 눈금이 더 이상 나타나지 않습니다.**

- **에이전트 턴 종료가 이전 로그에 의해 오도되지 않습니다.** 네이티브 턴 ID를 기준으로 기록하며, 새 도구가 시작될 때만 턴을 다시 엽니다. 그래픽 런처에서 누출된 훅 이벤트는 무시합니다.

- **에이전트 이름이 올바르게 표시됩니다.** Crush, Kilo Code가 더 이상 잘못된 라벨을 사용하지 않습니다.

- **pi / kimi가 네이티브 세션으로 이어서 대화할 수 있습니다.**

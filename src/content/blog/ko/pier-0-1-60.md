Pier 0.1.60(2026-11-15)이 출시되었습니다. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 추가

- **Files에서 PDF, Word, Excel을 바로 확인할 수 있습니다.** `.pdf` / `.docx` / `.xlsx` 파일을 더블클릭하면 패널 안에서 읽기 전용으로 열립니다. PDF는 페이지 넘김, 확대/축소, 너비에 맞춤을 지원하며 페이지 내 링크는 평소처럼 클릭할 수 있습니다. Word는 원본 레이아웃대로 표시됩니다(복잡한 레이아웃은 원본 파일과 다를 수 있음). Excel은 여러 워크시트, 숫자 형식, 문서에 포함된 열 너비를 유지하며, 열 너비는 드래그할 수 있고 워크시트별로 기억됩니다. 셀은 바로 복사할 수 있습니다. PPTX, 이전 버전 `.doc` / `.xls`, 암호화된 문서는 이유를 안내하고 '기본 앱에서 열기' 항목을 제공합니다. 64 MB를 초과하는 문서에도 명확한 안내가 표시됩니다.

## 수정

- **미리보기 중 파일이 변경되면 현재 버전을 확인하라는 안내가 표시됩니다.** 읽는 중 파일이 변경된 경우와 문서가 크기 한도를 초과한 경우가 이제 두 가지 안내로 구분됩니다. 전자의 경우 '다시 로드'를 제공하며, 더 이상 오래된 페이지를 최신 내용으로 취급하지 않습니다.
- **삭제된 문서 탭이 남아 있고 마지막 미리보기를 계속 표시합니다.** 파일이 디스크에서 삭제된 뒤 더 이상 페이지 전체가 비거나 읽기 실패가 표시되지 않습니다. 상단에는 삭제됨 안내가 유지되며, 파일을 복구하면 다시 미리 볼 수 있습니다.
- **터미널 위에 겹쳐 표시되는 검색 바, 메뉴, 자동 완성 목록이 올바른 둥근 모서리와 그림자를 되찾았습니다.** 오버레이 외형은 실제로 렌더링된 카드에서 샘플링하도록 바뀌어, 둥근 모서리, 그림자, 페이드 인/아웃이 화면과 일치합니다. 캡슐형 요소에 더 이상 직각이 드러나지 않고, 메뉴에 더 이상 '각은 있지만 그림자는 없는' 현상이 나타나지 않습니다.
- **탭 바에서 휠을 굴려도 탭 행이 탄성 바운스로 끌려 나오지 않습니다.** 탭 바는 콘텐츠 스크롤 영역이 아니므로 끝에서 멈춥니다. 오버플로 카운트(▾ N) 등은 제스처가 멈춘 뒤 한 번 갱신되며, 스크롤 중에는 더 이상 요동치지 않습니다.

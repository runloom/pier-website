Pier 0.1.58(2026-11-09)이 출시되었습니다. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 수정

- **에이전트가 백그라운드에서 연 분할 패널이 더 이상 `Last login` 빈 껍데기에 머물지 않습니다.** 분할 화면 세션은 창 식별 정보가 일치하지 않을 때 사라진 것으로 간주되어 매핑이 재구성되었고, 방금 열린 동료 패널이 연결을 잃어 프로세스가 시작되지 않았습니다. 이제 활성 상태 판단이 불확실할 때는 매핑을 유지하며, 백그라운드 분할 패널이 즉시 시작되고 실패한 자리표시자는 회수됩니다.
- **창 간 에이전트 세션 위치 지정이 더 이상 누락되지 않습니다.** 호스트 명령은 이전에 Electron 창 ID와 내부 창 ID를 혼용해 패널을 잘못된 창에 배치할 수 있었습니다. 이제 내부 창 ID로 통일해 정규화합니다.
- **설정이나 확인 모달을 열 때 터미널이 더 이상 사라지지 않습니다.** 모달 오버레이는 이전에 그리기 가능 영역으로 취급되어 터미널이 뚫린 부분을 메우는 데 사용되었고, 불투명한 배경에서는 터미널이 통째로 지워졌습니다. 이제 오버레이는 입력 캡처만 담당하고, 모달 카드는 터미널 위에 별도로 표시됩니다.

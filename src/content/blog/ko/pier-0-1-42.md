Pier 0.1.42(2026-09-11) 출시. 이번 버전 업데이트 내용은 다음과 같습니다.

## 추가

- **Canvas 인터랙티브 흐름도.** 작성자는 스윔레인, 단계, 연결선만 작성하고, 호스트가 검증한 뒤 주 경로, 우회, 반환, 실패 선을 그립니다. 스윔레인은 상단 바가 있는 상자이며, 단계, 그룹 상자, 노드 종류에서 파생된 범례를 겹쳐 표시할 수 있습니다. 정지 상태에서는 주 경로가 더 굵고 복구 밴드가 보입니다. 포인터를 올리면 관련 연결선이 방향을 따라 흐릅니다.
- **Canvas 인터페이스 흐름.** 다중 화면 경로는 프레임 표만 작성하면 됩니다. 호스트가 꺾은선, 시작 깃발, 범례, 라벨 위치를 그립니다.
- **파일을 삭제한 후에도 열려 있던 탭이 유지됩니다.** 본문은 계속 표시되고 위에 안내가 하나 표시됩니다. 저장하면 원래 경로로 다시 생성됩니다. 삭제로 인해 발생한 차이만으로는 미저장 점이 켜지지 않으며, 탭을 닫을 때도 저장할지 묻지 않습니다.
- **파일 트리와 검토 트리는 하이라이트 다중 선택을 지원합니다.** 선택은 집합이고, 활성화는 단일 항목입니다. 선택된 항목을 우클릭하면 전체 집합에 작업합니다.

## 변경

- **Canvas 스킬 템플릿과 프롬프트 중복 제거.** 각 셸 / 레시피마다 스타터 하나(컴포넌트 디렉터리에서 바로 머티리얼 캔버스를 보고, 더 이상 kit 템플릿을 따로 만들지 않음); 규칙은 SKILL, 해당 reference 또는 pack에만 작성합니다.
- **Markdown과 화이트보드의 흐름도가 종이 색상과 일치합니다.** 그룹, 노드, 연결선은 기본적으로 문서 종이와 동일한 색상 세트를 따릅니다.

## 수정

- **macOS에서 더 이상 사용하지 않는 화면 기록, 카메라, 마이크, 블루투스 권한을 요청하지 않습니다.** 시작할 때와 평소 사용 중에 이러한 권한을 묻지 않으며, 정식 빌드도 Electron 기본 수집 목적 설명을 더 이상 포함하지 않습니다. 이전 버전에서 화면 기록을 승인한 적이 있는데 업데이트 후에도 계속 요청한다면: Pier를 완전히 종료한 뒤 시스템 설정에서 해당 스위치를 껐다가 다시 켜고 시작하세요. 새 버전은 화면 기록이 더 이상 필요하지 않습니다.
- **흐름도가 올바른 순서로 그려집니다: 꺾은선은 카드 아래에, 호버 시에는 글로우, 복구 밴드는 더 이상 연결선에 색을 입히지 않습니다.**
- **터미널을 닫은 후 향상된 입력의 초안과 첨부 파일을 해제합니다.** 입력 상자를 접거나 탭을 전환해도 보내지 않은 내용은 유지됩니다. 터미널 닫기를 확인하면 본문, 편집 스냅샷, 댓글, 첨부 파일을 지우고, 아직 실행되지 않은 첨부 작업을 즉시 해제합니다. 이전 파일 요청이 아직 반환되지 않았더라도 마찬가지입니다. 늦게 도착한 결과는 새로 연 터미널에 영향을 주지 않습니다. 다른 창으로 성공적으로 이동한 뒤에도 원래 창은 이러한 입력 데이터를 해제하며, 실행 중인 터미널은 닫지 않습니다.
- **향상된 입력을 다시 연 후 첨부 파일과 전송 결과가 더 이상 새 초안을 방해하지 않습니다.** 파일 선택과 붙여넣기가 완료되면 현재 입력 상자에 기록되고, 접힌 동안 완료된 내용은 다시 열 때 복원됩니다. 이전 메시지 전송이 완료되어도 나중에 편집한 내용이 지워지지 않으며, 새로 연 입력 상자도 닫히지 않습니다. 전송 중에는 중복 제출이 금지되지만 본문은 계속 편집할 수 있습니다.
- **만료된 Grok 멤버십이 더 이상 현재 유효한 것으로 표시되지 않습니다.**
- **재시작 후 Grok 터미널에서 색상이 사라지지 않습니다.**
- **대형 검토 트리와 변경 비교가 정상적으로 스크롤됩니다.**
- **탭을 다른 창으로 복사할 때 원래 소스 탭이 유지됩니다.**
- **Markdown을 열 때 마지막으로 읽던 위치로 돌아갑니다.**
- **에이전트를 중지한 후에도 터미널 화면이 유지됩니다.** 에이전트를 중지하거나 프로세스가 종료된 후에도 터미널 내용은 패널에 남아 있습니다.

Pier 0.1.57(2026-11-09)이 릴리스되었습니다. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 수정

- **Files에서 웹 페이지를 미리 볼 때 더 이상 터미널을 가리지 않습니다.** 유리 또는 흐림 효과가 있는 HTML 페이지가 자체 레이어를 터미널 화면 위로 올려 내용이 겹치거나 잔상이 생기던 문제를 수정했습니다. 이제 터미널 화면은 항상 최상위에 있으며, 웹 페이지는 분할선, 떠 있는 탭 그룹, 자동 완성 목록 등 실제 컨트롤이 있는 부분에서만 표시되고 터미널 본체는 가려지지 않습니다.
- **터미널 상태 표시줄에 이전 프레임의 텍스트가 겹쳐 표시되지 않습니다.** 창 크기를 조절하거나 일부를 다시 그릴 때 하단 상태 줄의 칩이 잠시 두 개로 보이던 문제, 즉 오래된 칩은 이전 프레임의 잔상이던 문제를 수정했습니다. 이제 다시 그리기 전에 배경색을 먼저 깔고, 상태 줄에는 현재 내용만 유지합니다.

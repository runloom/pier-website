Pier 0.1.36(2026-09-02) 릴리스. 이번 버전의 업데이트 내용은 다음과 같습니다.

## 새로운 기능

- **작업 추적 패널.** 공식 플러그인이 GitHub, Linear, Jira의 이슈를 프로젝트 패널과 캔버스에 표시합니다. Linear / Jira는 워크플로별로 분류되고 드래그 앤 드롭 순서를 기억합니다. GitHub는 계속 담당자별로 분류됩니다.
- **모바일에서 같은 네트워크가 아니어도 PC에 연결 가능.** 페어링 후 릴레이 클라우드와 푸시를 통해 Mac을 깨우므로 PC와 같은 네트워크 세그먼트에 있을 필요가 없습니다.
- **탭을 창 밖으로 드래그.** Pier 바깥으로 드래그하면 원본 탭이 즉시 접히고, 대상 창은 예열된 후 나타납니다. 다시 튀어오르거나 잠시 빈 화면이 먼저 보이지 않습니다.
- **충돌 검토와 일반 비교가 동일한 뷰 사용.** 수정되지 않은 줄도 펼칠 수 있고, 파일 수준 충돌에는 작업 영역 본문과 해결 버튼이 계속 표시됩니다.
- **Markdown 미리보기 왼쪽에 HEAD 기준 변경 표시 막대.** 가는 슬롯이 소스 코드 검토와 정렬되어 주석과 개요를 가리지 않습니다.
- **Markdown 테이블 열 너비를 드래그로 조정하고, 테이블 헤더별로 기억.** 셀을 수정해도 열 너비가 유지됩니다. 놓아야 저장되고 Escape는 취소합니다. 미리보기에서 우클릭하면 소스 코드로 돌아갈 수 있습니다.
- **보드는 마지막으로 본 위치를 기억.** 팬 또는 확대/축소 후 월드 좌표 중심을 기준으로 복원합니다. 이미지, 차트, Markdown, 보드가 동일한 확대/축소 컨트롤을 공유합니다.
- **경로 복사가 별도 메뉴 항목으로 분리.** 파일 탭, 트리, 검색에서 경로 또는 상대 경로를 복사할 수 있고 해당 단축키가 표시됩니다. 편집기와 검토 비교에서는 계속 범위가 포함된 경로를 복사합니다.
- **우클릭 메뉴가 표면에 따라 기본 작업을 정렬.** 검토 트리는 스테이징 우선, 터미널의 찾기와 화면 지우기는 복사/붙여넣기와 첫 번째 그룹을 다투지 않습니다.
- **편집기 ⌘D로 다음 일치 항목도 계속 선택.** VS Code와 동일하며 분할 화면 단축키는 터미널에만 적용됩니다.
- **루트 README가 중영일한 지원.** GitHub 기본값은 여전히 간체 중국어이며, 상단에서 English, 日本語, 한국어로 전환할 수 있습니다.
- **CLI 사용자 매뉴얼이 중영일한 지원.** GitHub 진입점 `.pier/canvases/pier-cli-user-manual/README.md` 기본값은 여전히 간체 중국어이며, 상단에서 English, 日本語, 한국어로 전환할 수 있습니다. 앱 내 Canvas는 여전히 중국어입니다.

## 변경 사항

- **`/pier-canvas`에서 셸을 지정하지 않으면 에이전트가 skill로 추론.** 호스트는 `locale=`만 주입하고 키워드로 `mode` / `recipe` / `content`를 넣지 않습니다. 인터페이스 초안은 보드로, 결정 초안은 읽기 흐름으로 이동합니다. 명시적 매개변수는 여전히 우선하며, `/pier-canvas`만 입력하면 여전히 결정 초안입니다.
- **설정의 플러그인 행과 언어 서비스가 더 간결해짐.** 플러그인 행에는 이름과 작업만 남고, 언어 서비스는 세로 목록으로 바뀌었으며 다음 단계는 설치입니다.
- **명령 팔레트와 설정의 git 그룹이 GIT로 표기.** 플러그인 이름, 설정 제목, 명령 그룹, 명령 접두사가 통일되었습니다.

## 수정 사항

- **보드 컴파일 실패 시 빈 상태로 표시.** 파일을 수정한 후 핫 업데이트가 계속 실패하면 더 이상 이전 버전 보드 위에 경고를 덮지 않습니다. 미리보기가 가능한 경고, 저장 실패, 작업 영역 외 경로, 검토 부분 결과는 패널 상단 가장자리에 붙는 한 줄 알림으로 변경되었습니다.
- **밝은 색상 작업대에서 캔버스 프레임 제목을 읽을 수 있음.** 프레임 이름과 설명은 작업대 밝기에 따라 텍스트 색상을 바꾸며, 더 이상 호스트 다크 테마의 흰색 글자를 따르지 않습니다. 프레임 안의 제품 인터페이스는 여전히 앱 테마를 따릅니다.
- **파일, git, 터미널의 실시간 업데이트가 더 이상 유실되지 않음.** 디렉터리 폭주 상황에서도 따라잡을 수 있고, 터미널 상태 전달이 큐에 의해 버려지지 않습니다.
- **디렉터리가 나중에 저장소가 된 경우 상태 표시줄에 git 정보가 채워집니다.**
- **검토에서 작업을 실행해도 현재 패널을 빼앗지 않음.** 백그라운드로 실행되며 진행률이 원래 패널 위에 겹쳐 표시됩니다.
- **툴팁의 작은 삼각형이 점 하나로 줄어들지 않습니다.**
- **명령 목록에 항목이 하나뿐일 때 그룹 제목이 붙지 않습니다.** 명령 팔레트 빈 상태에서는 자주 쓰는 항목을 '최근'으로 모읍니다.
- **절대 경로를 붙여넣어도 현재 디렉터리에 이어붙지 않습니다.** 동작이 VS Code / Zed와 동일해졌습니다.
- **중국어 입력기에서 Enter를 눌러도 후보 문자가 깨지지 않습니다.**
- **터미널에서 드래그 선택해도 시스템 클립보드를 덮어쓰지 않습니다.** 드래그 선택은 프라이빗 클립보드로 들어가고, 복사, 붙여넣기, 전체 선택이 키보드 게이트에 삼켜지지 않습니다.
- **창을 넘어 복사한 후 붙여넣기가 더 이상 비어 있지 않습니다.**
- **시스템 외관 변경이 창에 즉시 적용됩니다.**
- **패널 그룹을 닫은 후 포커스는 가장 최근에 사용한 그룹에 유지.** 더 이상 왼쪽 위의 가장 오래된 그룹으로 점프하지 않습니다.
- **Kimi가 빈 턴 실패 후 상태를 복구할 수 있습니다.** 인증 요청은 대기 상태로 들어갑니다.
- **에이전트 업데이트 시간 초과 시 npm 프로세스 종료 원문이 더 이상 표시되지 않습니다.**
- **프로젝트 메모리가 이미 작성된 TOML MCP 항목을 부분 연결로 잘못 보고하지 않습니다.**
- **모바일 뒤로 가기 키가 원래 세션으로 돌아갑니다.** 다중 창이 더 이상 잘못된 터미널에 바인딩되지 않으며, 작업대 터미널 제목이 데스크톱 탭 짧은 이름과 일치합니다.
- **기기 권한이 해제되면 모바일에서 즉시 알림이 표시되며, 일반적인 연결 끊김으로 표시되지 않습니다.** 같은 머신의 LAN과 릴레이 클라우드 항목은 한 줄로 합쳐집니다.

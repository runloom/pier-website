Pier 0.1.32(2026-08-26)는 입력 강화 기능의 재설계에 집중했습니다. 이번 버전은 첨부 파일 처리를 "자리 표시자"에서 "인식 우선"으로 바꾸고, 입력 영역의 상호작용을 주류 채팅 입력 관례에 맞췄습니다.

## 첨부 트랙: 인식 우선

- 모든 첨부 파일은 **48×48** 균일 그리드로 표시됩니다: 이미지는 contain으로 축소, 텍스트와 붙여넣기 내용은 앞부분 축소판 노출, 기타 파일은 유형 아이콘만 표시하고 이름은 호버 툴팁에.
- 트랙의 `#n` 번호는 제거되어 시각적 노이즈가 줄었습니다.
- 첨부가 많으면 줄바꿈 없이 가로 스크롤됩니다.

## 입력 칩: 캡슐형으로 통일

입력 강화의 `@` 경로, 명령, 스킬, 첨부, review 칩이 모두 완전한 라운드 캡슐 스타일로 통일되어 나머지 UI와 일관성을 유지합니다.

## 초안과 구성 상태 완전 보존

- **프로그램 포커스는 커서를 끝에**: 입력을 다시 열거나 돌아오면 커서는 초안 끝(시작이 아닌)에 위치하며, 주류 채팅 입력 관례에 맞습니다. 본문 클릭은 기존처럼 클릭 위치로 이동합니다.
- **닫고 열어도 구성 보존**: 입력을 껐다 켜면 명령 / 스킬 / `@` / 첨부 / review 칩이 상단 첨부 트랙과 함께 그대로 복원되며, 텍스트로 퇴화하지 않습니다. 전송 후에는 평소처럼 비워집니다.

## Esc 계층적 종료

명령 / 스킬 / `@` / `#` 목록이 열려 있을 때 Esc를 누르면 목록만 닫히고 입력 카드 전체는 닫히지 않습니다. 목록을 닫은 후 Esc를 한 번 더 누르면 입력 영역이 닫힙니다.
